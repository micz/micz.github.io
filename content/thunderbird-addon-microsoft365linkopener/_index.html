With this addon you can open a shared link of a SharePoint or OneDrive file directly with the right app, instead of the browser.

How it works

  1. Install the addon from the Thunderbird Add-on site.
  2. Open a mail with a link to a shared SharePoint or OneDrive file.
  3. In the top right corner of the mail message, click the button to open the file directly in the Word, Excel or PowerPoint desktop app.
Privacy
