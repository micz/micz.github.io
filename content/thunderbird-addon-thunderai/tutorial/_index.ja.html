このチュートリアルでは、完全に動作するカスタムプロンプトを一から作成します。
目標は、メールへのフォーマルな返信の下書きを作成するプロンプトです。返信は適切な相手に宛てられ、その場で指定したトーンで書かれ、あなたの名前で署名されます。
カスタムプロンプト、標準のデータプレースホルダー、そしてカスタムデータプレースホルダーを組み合わせて使います。

最後まで進めると、この 3 つの要素がどのように連携するかがわかり、作成したいどのプロンプトにも同じ方法を応用できるようになります。

作成するもの

完成したプロンプトは、次のことを行います。

  1. メールから自動的に取得した元の送信者に宛てて返信します。
  2. 使用するたびにトーン（例：「フォーマル」「親しみやすく」「簡潔に」）を尋ねます。
  3. カスタムデータプレースホルダーとして一度だけ保存したあなたの名前で署名します。

最終的なプロンプトのテキストは次のようになります。

Write a reply to the following email.
Address the reply to: {%author%}
Tone: {%additional_text:tone%}
Sign the reply with: {%thunderai_custom_my_name%}

{%mail_text_body%}

ステップ 1 — 名前用のカスタムデータプレースホルダーを作成する

まず、作成するすべてのプロンプトに名前を入力しなくて済むように、名前を再利用可能なカスタムプレースホルダーとして保存します。
ThunderAI のオプションを開き、{{< ui_button "thunderai/tutorial/buttons/manage-data-ph.png" "Manage your data placeholders" >}} ボタンをクリックします。 Manage Data Placeholders ページが開きます。{{< ui_button "thunderai/tutorial/buttons/add-new.png" "Add New" >}} をクリックし、次の値でフォームに入力します。

  • ID：my_name — ThunderAI が thunderai_custom_ という接頭辞を付けるため、プロンプト内ではこのプレースホルダーは {%thunderai_custom_my_name%} になります。
  • Name：My Name — 自分でわかりやすい説明的な名前です。
  • Data Placeholder Text：あなたのフルネーム（例：山田 太郎）。
  • Usable in prompts added to menu：Always — メールを読むときも作成するときも、すべてのプロンプトで使えるようにします。

{{< ui_button "thunderai/tutorial/buttons/add-ph.png" "Add the Data Placeholder" >}} をクリックしてから、{{< ui_button "thunderai/tutorial/buttons/save-all.png" "Save All" >}} をクリックします。このページでは、変更は保存したときにのみ記録されます。
これで、どのプロンプトでも {%thunderai_custom_my_name%} を使えるようになり、ThunderAI が自動的にあなたの名前に置き換えます。

ステップ 2 — カスタムプロンプトを作成する

ThunderAI のオプションに戻り、{{< ui_button "thunderai/customprompts/buttons/manage-prompts.png" "Manage your prompts" >}} ボタンをクリックして Manage Prompts ページを開きます。 {{< ui_button "thunderai/customprompts/buttons/new-prompt.png" "+ New prompt" >}} をクリックし、各フィールドに次のように入力します。

  • ID：formal_reply
  • Name：返信の下書き... — この名前が ThunderAI のメニューに表示されます。... は、プロンプトの実行前に入力を求めることを示すための便利な慣習です。
  • Prompt Text：以下のプロンプトをコピーします。 
    Write a reply to the following email.
Address the reply to: {%author%}
Tone: {%additional_text:tone%}
Sign the reply with: {%thunderai_custom_my_name%}

{%mail_text_body%}

プロンプトのテキストに {% と入力すると、ThunderAI が利用可能なプレースホルダーを候補として表示し、認識されたプレースホルダーはすべてハイライト表示されます。赤で表示されているものがあれば、書き方を確認してください。

使用しているプレースホルダーについての補足です。

  • {%author%} — メールの作成者（名前とメールアドレス）を挿入する標準のプレースホルダーです。
  • {%additional_text:tone%} — ユーザー入力用のプレースホルダーです。このプロンプトを実行するたびに、ThunderAI がトーンの入力を求めます。入力欄の横に ID tone が表示されるので、何を入力すればよいかがわかります。
  • {%thunderai_custom_my_name%} — ステップ 1 で作成したカスタムデータプレースホルダーです。
  • {%mail_text_body%} — メール本文のプレーンテキストです。これにより、AI が必要なコンテキストを得られます。

ステップ 3 — プロンプトの設定を構成する

引き続き新しいプロンプトで、次のオプションを設定します。

  • Add to menu：Reading an email — 受信したメールに返信するためのもので、メールの作成中に使うものではないためです。
  • Action：Do reply — AI の回答がメールへの返信に使われます。
  • Ask for additional text：オンにします — {%additional_text:tone%} プレースホルダーが機能するために必要です。オフのままにすると、ThunderAI がこのスイッチをハイライト表示します。
  • Always add the signature：オフのままにします — 名前はすでにプロンプト自体で追加しています。ThunderAI のオプションで設定した署名も付けたい場合はオンにしてください。

Connection [API] セクションでは、このプロンプトだけで使用する別の AI サービス、モデル、サーバーを選択することもできます。このチュートリアルでは必要ありません。デフォルトでは、プロンプトはオプションで設定した接続を使用します。

{{< ui_button "thunderai/customprompts/buttons/save.png" "Save" >}} をクリックします。プロンプトはすぐに保存され、メニューに追加されます。

ステップ 4 — 試してみる

  1. Thunderbird で受信したメールを開きます。
  2. ThunderAI のメニューを開き、返信の下書き... を選択します。
  3. AI チャットウィンドウが開き、[ID: tone] ラベルを表示して追加のテキストを求めます。フォーマルで簡潔に のように入力し、{{< ui_button "thunderai/tutorial/buttons/send.png" "Send" >}} をクリックします。
  4. すべてのプレースホルダーが置き換えられた状態でプロンプトが AI に送信されます。送信内容はチャットウィンドウで確認できます。
  5. AI が回答したら、{{< ui_button "thunderai/tutorial/buttons/use-answer.png" "Use this answer" >}} をクリックすると、回答のテキストを使った返信が開きます。ボタンの 2 行目には、オプションの設定に従って全員に返信するのか送信者のみに返信するのかが表示されます。横の矢印から、もう一方を選ぶこともできます。

次に試すこと

各要素がどのように組み合わさるかがわかったところで、次のような使い方も試してみてください。

  • カスタムプレースホルダーを追加する — 役職、会社名、定型の免責事項などを保存し、すべてのプロンプトで再利用できます。
  • ユーザー入力欄を増やす — 同じプロンプト内に、それぞれ異なる ID を持つ複数の {%additional_text:<id>%} プレースホルダーを使用できます。ThunderAI はそれらを順番に尋ねます。
  • テキスト比較ビューアーを有効にする — Substitute text アクションを使って校正や書き直しのプロンプトを作成する場合は、Enable the text comparison viewer をオンにすると、AI が提案した変更を使用する前に確認できます。
