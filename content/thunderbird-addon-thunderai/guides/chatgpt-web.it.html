L'integrazione con la ChatGPT Web Interface ti consente di usare ThunderAI senza una chiave API.
ThunderAI interagisce direttamente con il sito ChatGPT per tuo conto, quindi è sufficiente un account ChatGPT gratuito.

Chiave API richiesta Opzione gratuita Ideale per
No Sì (anche con un account ChatGPT gratuito) Iniziare subito, senza configurazioni di pagamento

Prerequisiti

  • Un account gratuito (o a pagamento) su chatgpt.com
  • Thunderbird con ThunderAI installato

Configurazione

Il modo più rapido è il Setup Wizard: aprilo dalla pagina di benvenuto di ThunderAI, dal popup della barra degli strumenti o dalla pagina delle impostazioni, e scegli ChatGPT Web Interface. Poi prosegui dal passo 3.
Per configurarla a mano, segui tutti i passi qui sotto.

1. Apri le impostazioni di ThunderAI

In Thunderbird, vai su Strumenti → Componenti aggiuntivi e temi → ThunderAI → Preferenze.

2. Seleziona la ChatGPT Web Interface

Nel pannello Connection Settings, scegli ChatGPT Web Interface nel menu a tendina Connection Type.

3. Concedi il permesso richiesto

ThunderAI necessita del permesso per accedere a chatgpt.com. Non lo chiede la pagina delle impostazioni, ma il popup di ThunderAI.

  1. Clicca sul pulsante ThunderAI nella barra degli strumenti. Finché il permesso manca, al posto dell'elenco dei prompt il popup mostra "To use the ChatGPT Web integration, you need to grant the required permission."
  2. Clicca su quel messaggio: la pagina di benvenuto di ThunderAI si apre in una nuova scheda.
  3. Clicca sullo stesso messaggio in cima alla pagina di benvenuto e accetta la richiesta di permesso di Thunderbird.
  4. Quando compare "Permission granted", cliccaci sopra per chiudere la scheda.

Dopo aver selezionato la ChatGPT Web Interface, puoi aprire la pagina di benvenuto anche dalla scheda Open the Welcome Page in cima alla pagina delle impostazioni: mostra la stessa richiesta.

Questo permesso è opzionale e viene utilizzato esclusivamente per interagire con il sito ChatGPT per tuo conto. ThunderAI non raccoglie né memorizza alcun dato.

4. Accedi a ChatGPT

Devi farlo solo una volta: Thunderbird mantiene la sessione attiva.
La prima volta che usi un prompt, ThunderAI apre la finestra di ChatGPT. Se non hai effettuato l'accesso te lo segnala: accedi con il tuo account in quella finestra, chiudila e lancia di nuovo il prompt.
Se l'accesso da quella finestra non funziona, usa il pulsante Open ChatGPT Tab nelle impostazioni di ThunderAI: apre chatgpt.com in una scheda di Thunderbird, dove puoi accedere. Poi chiudi la scheda e torna a usare ThunderAI.

5. Testa l'integrazione

Apri una qualsiasi email, clicca sul pulsante ThunderAI nella barra degli strumenti e seleziona un prompt (ad es. Summarize). ThunderAI apre una finestra di ChatGPT, invia il prompt e vi mostra la risposta.

Opzioni avanzate

Clicca su Advanced options nel pannello Connection Settings per mostrare queste impostazioni:

  • ChatGPT Web Model: il modello da usare. Se è vuoto o non valido, ChatGPT usa quello predefinito. Non funziona con un account ChatGPT gratuito.
  • ChatGPT Web Project e ChatGPT Web Custom GPT: un Progetto o un Custom GPT da usare sempre. Copia il valore dalla barra degli indirizzi quando il Progetto (/g/PROJECT-ID-PROJECT-NAME/project) o il Custom GPT (/g/CUSTOM-GPT-ID) è aperto in ChatGPT. Puoi impostarli anche sul singolo prompt, nella pagina dei prompt personalizzati.
  • ChatGPT Web temporary chat: usa una chat temporanea.
  • Wait time for page load: quanti millisecondi ThunderAI attende il caricamento della pagina di ChatGPT (predefinito 1000). Con un Progetto o un Custom GPT si aggiungono 1000 ms.

Anche il pulsante Open ChatGPT Tab applica il modello, il Progetto e il Custom GPT configurati.

Suggerimenti e limitazioni note

  • La velocità di risposta dipende dal sito ChatGPT e può variare. L'integrazione via API è generalmente più veloce e affidabile.
  • Gli account gratuiti sono soggetti ai limiti di utilizzo di ChatGPT (rate limit, disponibilità dei modelli).
  • Se ChatGPT modifica il layout del suo sito, l'integrazione potrebbe smettere di funzionare temporaneamente fino all'aggiornamento di ThunderAI. Consulta la pagina di stato per eventuali problemi noti.
  • Le funzioni AI elencate nella pagina delle impostazioni (Add Tags, Spam Filter, Summarize, Translate, Calendar Event e Task) richiedono un'integrazione API e non funzionano con la ChatGPT Web Interface. Puoi mantenere ChatGPT Web come connessione principale e assegnare a ciascuna di queste funzioni una propria connessione API nella sua pagina delle impostazioni. I tuoi prompt dal menu della barra degli strumenti continuano a funzionare con ChatGPT Web.

Risoluzione dei problemi

Il popup chiede un permesso invece di mostrare i prompt

Il permesso per chatgpt.com non è ancora stato concesso. Vedi il passo 3.

ThunderAI dice che non hai effettuato l'accesso, o non mostra nessuna risposta

Accedi a ChatGPT nella finestra di ChatGPT aperta da ThunderAI, chiudila e riprova. Se non funziona, accedi dalla scheda aperta dal pulsante Open ChatGPT Tab nelle impostazioni di ThunderAI.

"Could not locate the ChatGPT message box"

ThunderAI non ha trovato la casella di testo di ChatGPT, di solito dopo una modifica al sito ChatGPT. Clicca dentro la casella di testo di ChatGPT entro un minuto e ThunderAI prosegue. Se succede ogni volta, consulta la pagina di stato.

Le risposte sono lente o vanno in timeout

Di solito si tratta di un problema temporaneo con il sito ChatGPT. Attendi un momento e riprova, oppure considera di passare all'integrazione OpenAI API per prestazioni più affidabili.
