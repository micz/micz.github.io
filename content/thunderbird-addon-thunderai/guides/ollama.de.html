Die Integration mit Ollama ermöglicht es Ihnen, KI-Modelle lokal auf Ihrem eigenen Computer auszuführen.
Bei einer lokalen Installation verlassen Ihre E-Mails niemals Ihren Computer: kein API-Schlüssel, keine Cloud-Dienste, keine Kosten außer Ihrer Hardware.
Ein API-Schlüssel ist nur nötig, wenn Sie die gehostete API von Ollama nutzen oder einen Server hinter einem Proxy mit Authentifizierung.

API-Schlüssel erforderlich Kostenlose Option Privat / Lokal? Geeignet für
Nein (optional) Ja (völlig kostenlos, Sie nutzen Ihre Hardware) Ja (alles bleibt auf Ihrem Computer) Datenschutzbewusste Nutzer, sensible E-Mails, Offline-Nutzung

Voraussetzungen

  • Ollama installiert und auf Ihrem Computer aktiv (oder im lokalen Netzwerk erreichbar)
  • Mindestens ein in Ollama heruntergeladenes Modell
  • Thunderbird mit installiertem ThunderAI

Ollama installieren und ein Modell herunterladen

Falls Sie Ollama noch nicht installiert haben:

  1. Laden Sie es von ollama.com herunter und folgen Sie den Installationsanweisungen für Ihr Betriebssystem
  2. Öffnen Sie ein Terminal und laden Sie ein Modell herunter, zum Beispiel:
    ollama pull llama3
    Weitere gute Optionen für E-Mail-Aufgaben: mistral, phi3, gemma2
  3. Prüfen Sie, ob Ollama läuft:
    ollama list

CORS konfigurieren

Thunderbird-Erweiterungen laufen in einer abgeschotteten Umgebung, daher muss Ollama ihre Anfragen akzeptieren. Dafür gibt es zwei Wege:

  • Setzen Sie die Umgebungsvariable OLLAMA_ORIGINS auf moz-extension://* und starten Sie Ollama neu.
  • Oder erteilen Sie ThunderAI die Berechtigung, auf Ihren Ollama-Server zuzugreifen: mit der Schaltfläche Give permission to the current host in den ThunderAI-Einstellungen (unter "Problems setting CORS?") oder indem Sie die Anfrage bestätigen, die beim Testen der Verbindung erscheint. Bei einem Server auf localhost oder 127.0.0.1 fragt Thunderbird nach Zugriff auf alle Websites (<all_urls>).

Detailliertere CORS-Konfigurationen finden Sie auf der Informationsseite zu Ollama und CORS.

Einrichtung

Am schnellsten geht es mit dem Setup Wizard: Öffnen Sie ihn über die Willkommensseite von ThunderAI, das Popup in der Symbolleiste oder die Einstellungsseite, wählen Sie Ollama API (Local LLM), geben Sie die Serveradresse ein, wählen Sie ein Modell und testen Sie die Verbindung. Anschließend können Sie im Wizard die gewünschten KI-Funktionen aktivieren.
Für die manuelle Einrichtung folgen Sie den Schritten unten.

1. ThunderAI-Einstellungen öffnen

Gehen Sie in Thunderbird zu Extras → Add-ons und Themes → ThunderAI → Einstellungen.

2. Ollama-Integration auswählen

Wählen Sie im Bereich Connection Settings im Dropdown Connection Type die Option Ollama API (Local LLM).

3. Serveradresse festlegen

Geben Sie die URL Ihres Ollama-Servers in das Feld Host Address ein. Der Standardwert ist:

http://localhost:11434

Läuft Ollama auf einem anderen Rechner in Ihrem Netzwerk, ersetzen Sie localhost durch die IP-Adresse dieses Rechners.

Lassen Sie das Feld Ollama API Key bei einer normalen lokalen Installation leer. Es wird nur für die gehostete API auf ollama.com benötigt oder für einen selbst betriebenen Server hinter einem Proxy mit Authentifizierung.

4. Modell auswählen

Klicken Sie neben Ollama Models auf Update list und wählen Sie dann das gewünschte Modell aus der Liste.

5. Verbindung testen

Einstellungen werden gespeichert, sobald Sie sie ändern: Es gibt keine Speichern-Schaltfläche.
Klicken Sie in der Leiste unter den Verbindungseinstellungen auf Test now und bestätigen Sie die Berechtigungsanfrage von Thunderbird, falls sie erscheint (siehe CORS konfigurieren). Wenn alles in Ordnung ist, zeigt die Leiste "Connected — Ollama API (Local LLM) reachable". Öffnen Sie dann eine beliebige E-Mail, klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste und führen Sie einen Prompt aus.

Erweiterte Optionen

Klicken Sie im Bereich Connection Settings auf Advanced options, um die folgenden Einstellungen anzuzeigen. Sie passen sich an das ausgewählte Modell an.

  • System Prompt: wird zu Beginn jeder Unterhaltung gesendet, um dem Modell eine Rolle oder feste Anweisungen zu geben.
  • Enable thinking: lässt das Modell vor der Antwort nachdenken. Die verfügbaren Stufen hängen vom Modell ab und erscheinen, sobald es ausgewählt ist. Model default sendet nichts und überlässt die Entscheidung dem Modell, das bei manchen Modellen trotzdem nachdenkt: Wählen Sie Off, um das Nachdenken auszuschalten.
  • Temperature: höhere Werte machen die Antworten kreativer. Der Standardwert ist 0.8; empfohlen sind Werte zwischen 0 und 1.
  • Number of context tokens: wie viel Text das Modell berücksichtigen kann. ThunderAI zeigt das Maximum an, das das ausgewählte Modell unterstützt. Mit 0 gilt der Standardwert des Servers.
  • Keep model loaded: wie lange Ollama das Modell nach einer Anfrage im Speicher hält, z. B. 5m oder 30m, -1 für dauerhaft, 0 zum sofortigen Entladen. Leer bedeutet Standardwert des Servers (5 Minuten). Erhöhen Sie den Wert, wenn Add Tags, der Spamfilter oder die automatische Zusammenfassung bei eingehender Post laufen: sonst wird das Modell für jede Nachricht neu geladen.
  • Force JSON output: zwingt Ollama, gültiges JSON zurückzugeben, bei Modellen mit strukturierter Ausgabe.
  • Extra options: zusätzliche Parameter für Ollama als JSON-Objekt, z. B. {"top_p": 0.9, "seed": 42} oder {"num_predict": 512}.

Sie können diese Optionen auch für einen einzelnen Prompt festlegen, auf der Seite der benutzerdefinierten Prompts, sowie für jede KI-Funktion (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), mit der Schaltfläche Advanced options ihrer spezifischen Verbindung.

Tipps

  • Die Leistung hängt von Ihrer Hardware ab. Ein moderner Rechner mit mindestens 16 GB RAM bewältigt Modelle wie llama3 oder mistral problemlos. Eine GPU beschleunigt die Verarbeitung erheblich.
  • Kleinere Modelle (7B Parameter) sind schneller, aber weniger leistungsfähig; größere Modelle (13B, 70B) liefern bessere Ergebnisse, benötigen aber mehr Ressourcen.
  • Für E-Mail-Aufgaben sind mistral und llama3 beliebte Optionen mit einem guten Verhältnis von Qualität und Geschwindigkeit.
  • Wenn die automatischen Funktionen (Add Tags, Spam Filter, Summarize, Translate) bei einem langsamen Modell mit einem Timeout abbrechen, erhöhen Sie Special command timeout (ms) in den ThunderAI-Einstellungen.

Fehlerbehebung

"Failed to connect" oder keine Antwort

Prüfen Sie, ob Ollama tatsächlich läuft (ollama list in einem Terminal). Prüfen Sie, ob die Host Address in den ThunderAI-Einstellungen zu Ihrer Ollama-Installation passt.

CORS-Fehler

Die Variable OLLAMA_ORIGINS ist nicht gesetzt, oder Ollama wurde danach nicht neu gestartet. Wiederholen Sie die Schritte unter CORS konfigurieren, oder verwenden Sie stattdessen die Schaltfläche Give permission to the current host.

Leere Modellliste

Stellen Sie sicher, dass Sie mindestens ein Modell mit ollama pull <modellname> heruntergeladen haben und dass Ollama läuft.

Das Modell denkt nach, obwohl Sie das nicht möchten

Manche Modelle denken standardmäßig nach. Stellen Sie Enable thinking in den erweiterten Optionen auf Off.
