La integración con la OpenAI Compatible API te permite conectar ThunderAI a cualquier servidor que siga el formato de la API de OpenAI.
Esto incluye servidores locales como LM Studio, servicios alojados como DeepSeek, Grok, Mistral AI, OpenRouter y Perplexity, así como cualquier endpoint personalizado o autoalojado.

Clave de API requerida Opción gratuita Ideal para
Depende del servicio Depende del servicio (los servidores locales son gratuitos) Flexibilidad: servidores locales, proveedores alternativos, endpoints personalizados

Configuraciones predefinidas

ThunderAI incluye configuraciones predefinidas para los servicios compatibles con OpenAI más populares. Si usas uno de ellos, selecciona la configuración predefinida y solo proporciona tu clave de API:

Configuración predefinida Notas
DeepSeek API Rápido y rentable, modelos de razonamiento potentes
Grok API Los modelos Grok de xAI
Mistral API Los modelos alojados de Mistral AI
OpenRouter API Accede a muchos proveedores con una sola clave de API
Perplexity API Incluye modelos con búsqueda web integrada

Configuración

Lo más rápido es el Setup Wizard: ábrelo desde la página de bienvenida de ThunderAI, el popup de la barra de herramientas o la página de ajustes, elige OpenAI Compatible API, selecciona un servicio o introduce la dirección de tu servidor, elige un modelo y prueba la conexión. Después el asistente te permite activar las funciones de IA que quieras.
Para configurarla a mano, sigue los pasos de abajo.

1. Abre los ajustes de ThunderAI

En Thunderbird, ve a Herramientas → Complementos y temas → ThunderAI → Preferencias.

2. Selecciona la integración OpenAI Compatible API

En el panel Connection Settings, elige OpenAI Compatible API en el desplegable Connection Type.

3a. Usar un preajuste

Si tu proveedor tiene un preajuste, selecciónalo en Available Services y confirma. ThunderAI rellena la dirección del servidor, el ajuste "v1" y el nombre del chat, y vacía la lista de modelos. Introduce tu clave de API y continúa desde el paso 5.

3b. Configuración manual

Si tu proveedor no está en la lista, elige Custom y configúralo a mano:

  • Host Address: la URL base de tu servidor, sin /v1. Para LM Studio en local suele ser http://localhost:1234. También funciona la dirección de un servidor remoto.
  • Keep the "v1" compatibility (en las opciones avanzadas, activada por defecto): ThunderAI añade /v1 a la dirección, como en http://localhost:1234/v1/chat/completions. Desactívala si los endpoints de tu proveedor no tienen el segmento /v1.

4. Introduce tu clave de API (si es necesaria)

Introdúcela en el campo OpenAI Comp API Key, que es opcional. Los servidores locales como LM Studio normalmente no requieren clave de API, así que puedes dejarlo vacío. Los servicios alojados requieren una clave válida.

5. Elige un modelo

Haz clic en Update list junto a OpenAI Compatible API Models y después selecciona tu modelo en la lista.

Si el servidor no ofrece la lista de modelos, haz clic en Add manually y escribe el nombre del modelo tal como lo indica tu proveedor. Clear list vacía la lista.

6. Prueba la conexión

Los ajustes se guardan en cuanto los cambias: no hay botón Guardar.
Haz clic en Test now en la barra bajo los ajustes de conexión y acepta la solicitud de permiso de Thunderbird, si aparece. Si todo está bien, la barra muestra "Connected — OpenAI Compatible API reachable". Después abre cualquier correo, haz clic en el botón de ThunderAI en la barra de herramientas y ejecuta un prompt.

Opciones avanzadas

Haz clic en Advanced options en el panel Connection Settings para mostrar estos ajustes:

  • Keep the "v1" compatibility: consulta el paso 3b.
  • Chat Name: el nombre con el que aparece la IA en la ventana de chat de ThunderAI.
  • Temperature: entre 0 y 2. Los valores más altos hacen la salida más aleatoria, los más bajos más precisa.
  • Extra body data: parámetros adicionales como objeto JSON, para opciones que el servicio admite pero ThunderAI no muestra, p. ej. {"top_p": 0.9}, o {"chat_template_kwargs": {"thinking": false}} para desactivar el modo de razonamiento en los servidores que lo admiten.

También puedes definir estas opciones en un solo prompt, en la página de prompts personalizados, y en cada función de IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con el botón Advanced options de su conexión específica.

LM Studio — configuración rápida

LM Studio ofrece un servidor local con una API compatible con OpenAI y una interfaz gráfica para descargar y gestionar modelos.

  1. Descarga e instala LM Studio desde lmstudio.ai
  2. Descarga el modelo que prefieras desde el catálogo de modelos de LM Studio
  3. En LM Studio, inicia el servidor local
  4. En ThunderAI, elige Custom, pon la Host Address en http://localhost:1234, deja activada la compatibilidad "v1", deja vacía la clave de API y selecciona tu modelo

Consejos

  • OpenRouter es una gran opción si quieres acceder a muchos modelos distintos (incluidos Claude, Gemini y Mistral) con una sola clave de API y una sola cuenta de facturación.
  • Con servidores locales, el rendimiento depende de tu hardware — consulta la guía de Ollama para consejos de hardware.
  • Si las solicitudes fallan con un error de CORS y no puedes cambiar la configuración del servidor, haz clic en Give permission to the current host en los ajustes de ThunderAI (bajo "Problems setting CORS?"). Para un servidor en localhost o 127.0.0.1, Thunderbird pide acceso a todos los sitios (<all_urls>).
  • Si se supera el límite de solicitudes o la cuota del servicio mientras ThunderAI procesa varios correos (Add Tags, Spam Filter, Summarize, Translate), el procesamiento se detiene solo e indica cuántos mensajes se procesaron.

Solución de problemas

"Connection refused" en un servidor local

Asegúrate de que el servidor local (p. ej. LM Studio) se está ejecutando y de que la Host Address en ThunderAI coincide con el puerto en el que escucha.

Error "401 Unauthorized"

Comprueba tu clave de API. Para servidores locales que no requieren clave, prueba con un valor ficticio como none. Algunos servidores rechazan el campo de clave vacío.

Lista de modelos vacía

Haz clic en Add manually y escribe el nombre del modelo tal como lo indica la documentación de tu proveedor o servidor.

"404 Not Found", o errores causados por el "v1" en la URL

Comprueba que la Host Address no termina en /v1, ya que ThunderAI lo añade cuando Keep the "v1" compatibility está activada. Si los endpoints de tu proveedor no tienen /v1, desactiva esta opción.
