L'intégration OpenAI API connecte ThunderAI directement aux serveurs d'OpenAI via une clé API.
Par rapport à l'interface web, elle est plus rapide, plus fiable et vous donne un contrôle explicite sur le modèle utilisé.

Clé API requise Option gratuite Idéal pour
Oui Non (facturation à l'usage) Accès stable et rapide aux modèles ChatGPT

Prérequis

  • Un compte OpenAI avec accès à l'API activé
  • Une clé API valide
  • Thunderbird avec ThunderAI installé

Note : l'utilisation de l'API OpenAI est facturée séparément d'un abonnement ChatGPT. Même si vous avez ChatGPT Plus, vous devez quand même ajouter des crédits à votre compte API.

Obtenir une clé API

  1. Accédez à platform.openai.com/api-keys
  2. Cliquez sur Create new secret key
  3. Donnez-lui un nom (ex. : « ThunderAI ») et cliquez sur Create
  4. Copiez la clé immédiatement, elle ne sera plus affichée

Configuration

Le plus rapide est le Setup Wizard : ouvrez-le depuis la page d'accueil de ThunderAI, le popup de la barre d'outils ou la page des paramètres, choisissez ChatGPT OpenAI API, collez votre clé API, choisissez un modèle et testez la connexion. L'assistant vous permet ensuite d'activer les fonctions IA souhaitées.
Pour une configuration manuelle, suivez les étapes ci-dessous.

1. Ouvrir les paramètres de ThunderAI

Dans Thunderbird, accédez à Outils → Modules complémentaires et thèmes → ThunderAI → Préférences.

2. Sélectionner l'intégration OpenAI API

Dans le panneau Connection Settings, choisissez ChatGPT OpenAI API dans la liste déroulante Connection Type.

3. Saisir votre clé API

Collez votre clé API dans le champ ChatGPT API Key. La clé est stockée localement dans Thunderbird et n'est envoyée qu'aux serveurs d'OpenAI.

4. Choisir un modèle

Cliquez sur Update list à côté de ChatGPT Models. La première fois, Thunderbird demande la permission d'accéder à openai.com : acceptez-la, sinon ThunderAI ne peut pas joindre OpenAI. Sélectionnez ensuite le modèle à utiliser dans la liste.

5. Tester la connexion

Les paramètres sont enregistrés dès que vous les modifiez : il n'y a pas de bouton Enregistrer.
Cliquez sur Test now dans la barre sous les paramètres de connexion. Si tout va bien, elle affiche "Connected — ChatGPT OpenAI API reachable". Ouvrez ensuite n'importe quel e-mail, cliquez sur le bouton ThunderAI dans la barre d'outils et lancez un prompt.

Options avancées

Cliquez sur Advanced options dans le panneau Connection Settings pour afficher les paramètres ci-dessous. Laissez-les vides ou sur Default pour laisser l'API décider. Ils s'adaptent au modèle sélectionné : un paramètre que le modèle n'accepte pas est désactivé, avec une note qui en explique la raison. La valeur enregistrée est conservée, au cas où vous reviendriez à un autre modèle.

  • Temperature et Top P : à quel point la réponse est aléatoire ou ciblée. Les modèles de raisonnement ne les acceptent pas : utilisez plutôt Reasoning effort.
  • Reasoning effort et Reasoning summary : combien le modèle raisonne, et s'il faut afficher dans la discussion un résumé de son raisonnement. Modèles de raisonnement uniquement.
  • Verbosity : la longueur et le niveau de détail de la réponse, sur les modèles qui le prennent en charge.
  • Max output tokens : la longueur maximale de la réponse.
  • Developer Messages : instructions et contexte envoyés au modèle avec chaque prompt.
  • Output format : texte simple (par défaut), un objet JSON, ou du JSON qui suit un schéma que vous saisissez.
  • Truncation, Service tier, Prompt cache key, Safety identifier et Include encrypted reasoning : options des requêtes OpenAI, décrites dans la référence de l'API OpenAI.
  • Use storage : si cochée, OpenAI conserve vos discussions.
  • Extra body data : paramètres supplémentaires sous forme d'objet JSON, pour les options que ThunderAI n'affiche pas.

Vous pouvez aussi définir ces options pour un seul prompt, dans la page des prompts personnalisés, et pour chaque fonction IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), avec le bouton Advanced options de sa connexion spécifique.

Conseils

  • L'utilisation de l'API est mesurée en tokens. Les e-mails sont généralement courts, les coûts sont donc le plus souvent très faibles. Vérifiez votre consommation sur platform.openai.com/usage.
  • OpenAI ajoute régulièrement de nouveaux modèles. Cliquez sur Update list pour voir les plus récents.
  • Si la limite de requêtes ou le quota d'OpenAI est dépassé pendant que ThunderAI traite plusieurs e-mails (Add Tags, Spam Filter, Summarize, Translate), le traitement s'arrête de lui-même et indique combien de messages ont été traités.

Dépannage

Erreur "Authentication failed — check your API key" ou "Invalid API key"

Vérifiez que vous avez copié la clé correctement, sans espaces en trop. Si la clé ne fonctionne toujours pas, générez-en une nouvelle depuis la plateforme OpenAI.

Erreur "You exceeded your current quota"

Votre compte API OpenAI n'a plus de crédits. Ajoutez-en sur platform.openai.com/settings/organization/billing.

Aucun modèle n'apparaît dans la liste

Si vous voyez "You have denied the optional permission needed to fetch models for this integration", cliquez de nouveau sur Update list et acceptez la demande de permission de Thunderbird. Sinon, vérifiez que votre clé API est valide et contrôlez votre connexion internet.

Le popup demande une permission au lieu d'afficher les prompts

La permission pour openai.com n'a pas encore été accordée. Cliquez sur le message dans le popup : la page d'accueil de ThunderAI s'ouvre. Cliquez-y sur le même message et acceptez la demande de Thunderbird. Vous pouvez aussi l'accorder à l'étape 4.
