La integración con la OpenAI API conecta ThunderAI directamente con los servidores de OpenAI mediante una clave de API.
En comparación con la interfaz web, es más rápida, más fiable y te da control explícito sobre qué modelo usar.

Clave de API requerida Opción gratuita Ideal para
Sí No (facturación por uso) Acceso estable y rápido a los modelos de ChatGPT

Requisitos previos

  • Una cuenta de OpenAI con acceso a la API habilitado
  • Una clave de API válida
  • Thunderbird con ThunderAI instalado

Nota: El uso de la API de OpenAI se factura por separado de una suscripción a ChatGPT. Aunque tengas ChatGPT Plus, igualmente necesitas añadir créditos a tu cuenta de API.

Cómo obtener una clave de API

  1. Ve a platform.openai.com/api-keys
  2. Haz clic en Create new secret key
  3. Dale un nombre (p. ej. "ThunderAI") y haz clic en Create
  4. Copia la clave inmediatamente; no se mostrará de nuevo

Configuración

Lo más rápido es el Setup Wizard: ábrelo desde la página de bienvenida de ThunderAI, el popup de la barra de herramientas o la página de ajustes, elige ChatGPT OpenAI API, pega tu clave de API, elige un modelo y prueba la conexión. Después el asistente te permite activar las funciones de IA que quieras.
Para configurarla a mano, sigue los pasos de abajo.

1. Abre los ajustes de ThunderAI

En Thunderbird, ve a Herramientas → Complementos y temas → ThunderAI → Preferencias.

2. Selecciona la integración OpenAI API

En el panel Connection Settings, elige ChatGPT OpenAI API en el desplegable Connection Type.

3. Introduce tu clave de API

Pega tu clave de API en el campo ChatGPT API Key. La clave se guarda localmente en Thunderbird y solo se envía a los servidores de OpenAI.

4. Elige un modelo

Haz clic en Update list junto a ChatGPT Models. La primera vez, Thunderbird pide permiso para acceder a openai.com: acéptalo, o ThunderAI no podrá conectar con OpenAI. Después selecciona en la lista el modelo que quieres usar.

5. Prueba la conexión

Los ajustes se guardan en cuanto los cambias: no hay botón Guardar.
Haz clic en Test now en la barra bajo los ajustes de conexión. Si todo está bien, muestra "Connected — ChatGPT OpenAI API reachable". Después abre cualquier correo, haz clic en el botón de ThunderAI en la barra de herramientas y ejecuta un prompt.

Opciones avanzadas

Haz clic en Advanced options en el panel Connection Settings para mostrar los ajustes de abajo. Déjalos vacíos o en Default para que decida la API. Se adaptan al modelo seleccionado: un ajuste que el modelo no acepta se desactiva, con una nota que explica el motivo. El valor guardado se conserva, por si vuelves a otro modelo.

  • Temperature y Top P: cuán aleatoria o precisa es la respuesta. Los modelos de razonamiento no los aceptan: usa Reasoning effort en su lugar.
  • Reasoning effort y Reasoning summary: cuánto razona el modelo, y si se muestra en el chat un resumen de su razonamiento. Solo modelos de razonamiento.
  • Verbosity: cuán larga y detallada es la respuesta, en los modelos que lo admiten.
  • Max output tokens: la longitud máxima de la respuesta.
  • Developer Messages: instrucciones y contexto que se envían al modelo con cada prompt.
  • Output format: texto simple (predeterminado), un objeto JSON, o JSON que sigue un esquema que introduces tú.
  • Truncation, Service tier, Prompt cache key, Safety identifier e Include encrypted reasoning: opciones de las solicitudes a OpenAI, descritas en la referencia de la API de OpenAI.
  • Use storage: si está marcada, OpenAI guarda tus chats.
  • Extra body data: parámetros adicionales como objeto JSON, para opciones que ThunderAI no muestra.

También puedes definir estas opciones en un solo prompt, en la página de prompts personalizados, y en cada función de IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con el botón Advanced options de su conexión específica.

Consejos

  • El uso de la API se mide en tokens. Los correos suelen ser cortos, así que los costes suelen ser muy bajos. Consulta tu consumo en platform.openai.com/usage.
  • OpenAI añade nuevos modelos con regularidad. Haz clic en Update list para ver los más recientes.
  • Si se supera el límite de solicitudes o la cuota de OpenAI mientras ThunderAI procesa varios correos (Add Tags, Spam Filter, Summarize, Translate), el procesamiento se detiene solo e indica cuántos mensajes se procesaron.

Solución de problemas

Error "Authentication failed — check your API key" o "Invalid API key"

Comprueba que has copiado la clave correctamente, sin espacios de más. Si la clave sigue fallando, genera una nueva desde la plataforma de OpenAI.

Error "You exceeded your current quota"

Tu cuenta de API de OpenAI se ha quedado sin créditos. Añade más en platform.openai.com/settings/organization/billing.

No aparece ningún modelo en la lista

Si ves "You have denied the optional permission needed to fetch models for this integration", haz clic de nuevo en Update list y acepta la solicitud de permiso de Thunderbird. Si no, comprueba que tu clave de API es válida y revisa tu conexión a internet.

El popup pide un permiso en lugar de mostrar los prompts

Aún no se ha concedido el permiso para openai.com. Haz clic en el mensaje del popup: se abre la página de bienvenida de ThunderAI. Haz clic allí en el mismo mensaje y acepta la solicitud de Thunderbird. También puedes concederlo desde el paso 4.
