Google Gemini との連携により、Gemini API を通じて ThunderAI を Google の Gemini AI モデルに接続できます。
System Instruction や Thinking Budget などの詳細オプションにも対応しており、モデルの動作を細かく制御したい上級ユーザーに便利です。

API キー 無料オプション おすすめの用途
必要 あり（十分な無料枠あり） Google のエコシステムを好む方、無料の API を使いたい方

前提条件

  • Google アカウント
  • Gemini API キー（無料枠あり）
  • ThunderAI をインストールした Thunderbird

API キーの取得

  1. aistudio.google.com/apikey にアクセスします
  2. Create API key をクリックします
  3. 既存の Google Cloud プロジェクトを選択するか、新しいプロジェクトを作成します
  4. 生成された API キーをコピーします

Gemini API には十分なレート制限の無料枠があり、個人でのメール利用に適しています。より高いスループットが必要な場合は、有料プランも利用できます。

セットアップ

最も簡単な方法は Setup Wizard です。ThunderAI のウェルカムページ、ツールバーのポップアップ、または設定ページから開き、 Google Gemini API を選択して API キーを貼り付け、モデルを選んで接続をテストします。 その後、ウィザードで使いたい AI 機能を有効にできます。
手動で設定する場合は、以下の手順に従ってください。

1. ThunderAI の設定を開く

Thunderbird で ツール → アドオンとテーマ → ThunderAI → 設定 を開きます。

2. Google Gemini 連携を選択する

Connection Settings パネルで、Connection Type のドロップダウンから Google Gemini API を選択します。

3. API キーを入力する

API Key 欄に API キーを貼り付けます。キーは Thunderbird 内にローカルで保存され、Google のサーバー以外に送信されることはありません。

4. モデルを選択する

Google Gemini API Models の横にある Update list をクリックし、一覧から使用するモデルを選択します。

5. 接続をテストする

設定は変更するとすぐに保存されます。保存ボタンはありません。
接続設定の下にあるバーの Test now をクリックします。Thunderbird が generativelanguage.googleapis.com へのアクセス権限を求めた場合は、承認してください。問題がなければ、バーに "Connected — Google Gemini API reachable" と表示されます。その後、任意のメールを開き、ツールバーの ThunderAI ボタンをクリックしてプロンプトを実行します。

詳細オプション

Connection Settings パネルの Advanced options をクリックすると、以下の設定が表示されます。 モデルの既定値を使う場合は、欄を空欄のままにしてください。

  • System Instruction: すべてのプロンプトに共通する固定のコンテキストです。たとえば、常に丁寧な文体で、特定の言語で、または特定の役割で回答させることができます。
  • Thinking Budget: モデルが回答前の推論に使えるトークン数です。0 を入力すると思考がオフになり、-1 を入力すると動的な思考になります。モデルが思考に対応していない場合は、空欄のままにしてください。
  • Temperature（0.0～2.0）、Top P、Top K: 回答のランダムさ、または的確さを調整します。Top K に対応していないモデルもあります。
  • Max output tokens: 回答の最大の長さです。空欄または 0 の場合は、モデルに任せます。
  • Extra body data: ThunderAI に表示されないオプション用の、Gemini API への追加パラメーターです。JSON オブジェクトで指定します（例: {"generationConfig": {"seed": 42}}）。 generationConfig 内のキーは、ThunderAI が作成するキーとマージされます。

これらのオプションは、カスタムプロンプトのページで個々のプロンプトに設定することもできます。また、各 AI 機能（Add Tags、Spam Filter、 Summarize、Translate、Calendar Event、Task）にも、それぞれの専用接続の Advanced options ボタンから設定できます。

ヒント

  • 無料枠には 1 分あたり・1 日あたりのリクエスト制限がありますが、通常は個人利用には十分です。現在の制限は Google AI Studio で確認してください。
  • ThunderAI が複数のメールを処理している間（Add Tags、Spam Filter、Summarize、Translate）に制限に達した場合、処理は自動的に停止し、処理済みのメッセージ数と、Google から通知があればどれだけ待つ必要があるかが表示されます。
  • System Instruction は、メールアシスタントに共通のルールを指定したい場合に特に便利です。

トラブルシューティング

"Authentication failed — check your API key" または "API key not valid" エラー

キーが正しくコピーされているか確認してください。必要に応じて、AI Studio で新しいキーを生成してください。

"Model not found" またはモデルの一覧が空

API キーが Gemini モデルにアクセスできることを確認してください。制限のある Google Cloud プロジェクトで作成したキーでは、利用できるモデルが限られる場合があります。

詳細オプションを変更した後にリクエストが失敗する

モデルによっては、すべてのオプションを受け付けるわけではありません（たとえば Top K や、思考に対応していないモデルでの Thinking Budget）。そのオプションを空欄にして、再度お試しください。
