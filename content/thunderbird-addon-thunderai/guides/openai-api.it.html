L'integrazione con OpenAI API connette ThunderAI direttamente ai server di OpenAI tramite una chiave API.
Rispetto all'interfaccia web, è più veloce, più affidabile e ti offre il controllo esplicito sul modello da utilizzare.

Chiave API richiesta Opzione gratuita Ideale per
Sì No (pagamento a consumo) Accesso stabile e veloce ai modelli ChatGPT

Prerequisiti

  • Un account OpenAI con accesso alle API abilitato
  • Una chiave API valida
  • Thunderbird con ThunderAI installato

Nota: l'utilizzo dell'API OpenAI viene fatturato separatamente rispetto all'abbonamento ChatGPT. Anche se hai ChatGPT Plus, devi comunque aggiungere crediti al tuo account API.

Ottenere una chiave API

  1. Vai su platform.openai.com/api-keys
  2. Clicca su Create new secret key
  3. Assegnagli un nome (ad es. "ThunderAI") e clicca su Create
  4. Copia subito la chiave: non verrà mostrata di nuovo

Configurazione

Il modo più rapido è il Setup Wizard: aprilo dalla pagina di benvenuto di ThunderAI, dal popup della barra degli strumenti o dalla pagina delle impostazioni, scegli ChatGPT OpenAI API, incolla la chiave API, scegli un modello e testa la connessione. Poi il wizard ti permette di attivare le funzioni AI che ti servono.
Per configurarla a mano, segui i passi qui sotto.

1. Apri le impostazioni di ThunderAI

In Thunderbird, vai su Strumenti → Componenti aggiuntivi e temi → ThunderAI → Preferenze.

2. Seleziona l'integrazione OpenAI API

Nel pannello Connection Settings, scegli ChatGPT OpenAI API nel menu a tendina Connection Type.

3. Inserisci la chiave API

Incolla la chiave API nel campo ChatGPT API Key. La chiave è memorizzata localmente in Thunderbird e viene inviata solo ai server di OpenAI.

4. Scegli un modello

Clicca su Update list accanto a ChatGPT Models. La prima volta Thunderbird chiede il permesso di accedere a openai.com: accettalo, altrimenti ThunderAI non può raggiungere OpenAI. Poi seleziona dall'elenco il modello che vuoi usare.

5. Testa la connessione

Le impostazioni vengono salvate appena le modifichi: non c'è un pulsante Salva.
Clicca su Test now nella barra sotto le impostazioni di connessione. Se è tutto a posto, mostra "Connected — ChatGPT OpenAI API reachable". Poi apri una qualsiasi email, clicca sul pulsante ThunderAI nella barra degli strumenti e lancia un prompt.

Opzioni avanzate

Clicca su Advanced options nel pannello Connection Settings per mostrare le impostazioni qui sotto. Lasciale vuote o su Default per lasciar decidere all'API. Si adattano al modello selezionato: un'impostazione che il modello non accetta viene disattivata, con una nota che spiega il motivo. Il valore salvato viene mantenuto, nel caso torni a un altro modello.

  • Temperature e Top P: quanto la risposta è casuale o mirata. I modelli di ragionamento non le accettano: usa invece Reasoning effort.
  • Reasoning effort e Reasoning summary: quanto ragiona il modello, e se mostrare nella chat un riepilogo del ragionamento. Solo per i modelli di ragionamento.
  • Verbosity: quanto è lunga e dettagliata la risposta, sui modelli che lo supportano.
  • Max output tokens: la lunghezza massima della risposta.
  • Developer Messages: istruzioni e contesto inviati al modello con ogni prompt.
  • Output format: testo semplice (predefinito), un oggetto JSON, oppure JSON che segue uno schema che inserisci tu.
  • Truncation, Service tier, Prompt cache key, Safety identifier e Include encrypted reasoning: opzioni delle richieste a OpenAI, descritte nella documentazione dell'API di OpenAI.
  • Use storage: se attivo, OpenAI conserva le tue chat.
  • Extra body data: parametri aggiuntivi in formato JSON, per le opzioni che ThunderAI non mostra.

Puoi impostare queste opzioni anche sul singolo prompt, nella pagina dei prompt personalizzati, e su ciascuna funzione AI (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con il pulsante Advanced options della sua connessione specifica.

Suggerimenti

  • L'uso dell'API si misura in token. Le email sono di solito brevi, quindi i costi sono in genere molto bassi. Controlla i consumi su platform.openai.com/usage.
  • OpenAI aggiunge regolarmente nuovi modelli. Clicca su Update list per vedere gli ultimi disponibili.
  • Se durante l'elaborazione di più email (Add Tags, Spam Filter, Summarize, Translate) si supera il limite di richieste o la quota di OpenAI, l'elaborazione si ferma da sola e ti dice quanti messaggi sono stati elaborati.

Risoluzione dei problemi

Errore "Authentication failed — check your API key" o "Invalid API key"

Verifica di aver copiato correttamente la chiave, senza spazi in più. Se la chiave continua a non funzionare, generane una nuova dalla piattaforma OpenAI.

Errore "You exceeded your current quota"

Il tuo account API di OpenAI ha esaurito i crediti. Aggiungine altri su platform.openai.com/settings/organization/billing.

Nell'elenco non compare nessun modello

Se vedi "You have denied the optional permission needed to fetch models for this integration", clicca di nuovo su Update list e accetta la richiesta di permesso di Thunderbird. Altrimenti verifica che la chiave API sia valida e controlla la connessione a internet.

Il popup chiede un permesso invece di mostrare i prompt

Il permesso per openai.com non è ancora stato concesso. Clicca sul messaggio nel popup: si apre la pagina di benvenuto di ThunderAI. Clicca lì sullo stesso messaggio e accetta la richiesta di Thunderbird. Puoi concederlo anche dal passo 4.
