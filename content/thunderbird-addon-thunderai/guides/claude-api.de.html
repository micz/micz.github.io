Die Integration mit der Claude API verbindet ThunderAI mit den Claude-KI-Modellen von Anthropic.
Claude ist bekannt für sorgfältig strukturierte Antworten und die effiziente Verarbeitung langer Dokumente — ideal zum Lesen und Verfassen detaillierter E-Mails.

API-Schlüssel erforderlich Kostenlose Option Geeignet für
Ja Nein (nutzungsbasierte Abrechnung) Detaillierte Analysen, lange E-Mails, strukturiertes Schreiben

Voraussetzungen

  • Ein Anthropic-Konto mit API-Zugang
  • Ein gültiger Claude API-Schlüssel
  • Thunderbird mit installiertem ThunderAI

API-Schlüssel erhalten

  1. Gehen Sie zu console.anthropic.com/settings/keys
  2. Klicken Sie auf Create Key
  3. Geben Sie ihm einen Namen und kopieren Sie den Schlüssel sofort — er wird nicht noch einmal angezeigt

Einrichtung

Am schnellsten geht es mit dem Setup Wizard: Öffnen Sie ihn über die Willkommensseite von ThunderAI, das Popup in der Symbolleiste oder die Einstellungsseite, wählen Sie Claude API, fügen Sie Ihren API-Schlüssel ein, wählen Sie ein Modell und testen Sie die Verbindung. Anschließend können Sie im Wizard die gewünschten KI-Funktionen aktivieren.
Für die manuelle Einrichtung folgen Sie den Schritten unten.

1. ThunderAI-Einstellungen öffnen

Gehen Sie in Thunderbird zu Extras → Add-ons und Themes → ThunderAI → Einstellungen.

2. Claude-API-Integration auswählen

Wählen Sie im Bereich Connection Settings im Dropdown Connection Type die Option Claude API.

3. API-Schlüssel eingeben

Fügen Sie Ihren API-Schlüssel in das Feld Claude API Key ein. Der Schlüssel wird lokal in Thunderbird gespeichert und nur an die Server von Anthropic gesendet.

4. Modell auswählen

Klicken Sie neben Claude Models auf Update list. Beim ersten Mal fragt Thunderbird nach der Berechtigung, auf anthropic.com zuzugreifen: Bestätigen Sie sie, sonst kann ThunderAI die Claude API nicht erreichen. Wählen Sie dann das gewünschte Modell aus der Liste.

Diese Berechtigung ist optional und dient nur der Kommunikation mit den API-Servern von Anthropic. ThunderAI erfasst keine Daten.

5. Verbindung testen

Einstellungen werden gespeichert, sobald Sie sie ändern: Es gibt keine Speichern-Schaltfläche.
Klicken Sie in der Leiste unter den Verbindungseinstellungen auf Test now. Wenn alles in Ordnung ist, erscheint "Connected — Claude API reachable". Öffnen Sie dann eine beliebige E-Mail, klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste und führen Sie einen Prompt aus.

Erweiterte Optionen

Klicken Sie im Bereich Connection Settings auf Advanced options, um die folgenden Einstellungen anzuzeigen. Sie passen sich an das ausgewählte Modell an: Eine Einstellung, die das Modell nicht akzeptiert, wird deaktiviert, mit einem Hinweis auf den Grund, und nicht gesendet. Der gespeicherte Wert bleibt erhalten, falls Sie zu einem anderen Modell zurückwechseln.

  • System Prompt: Anweisungen und Kontext, die mit jedem Prompt an das Modell gesendet werden.
  • Max Tokens: die maximale Länge der Antwort.
  • Effort: wie viel Denkaufwand das Modell in eine Anfrage steckt. Höhere Stufen liefern bessere Antworten bei komplexen Aufgaben, kosten aber mehr Tokens und dauern länger. Lassen Sie Default, damit die API entscheidet. Ältere Claude-Modelle unterstützen es nicht.
  • Extended thinking budget (tokens): bei den älteren Modellen die maximale Anzahl an Tokens, die das Modell zum Nachdenken verwenden darf. 0 schaltet das erweiterte Nachdenken aus. Der Wert muss mindestens 1024 und kleiner als Max Tokens sein: Andernfalls zeigen die Einstellungen eine Warnung und der Wert wird nicht gesendet.
  • Temperature (0.0–1.0), Top P und Top K: wie zufällig oder fokussiert die Antwort ist. Die neueren Claude-Modelle akzeptieren sie nicht: Verwenden Sie stattdessen Effort.
  • Stop sequences: Texte, bei denen das Modell aufhört zu schreiben, eine pro Zeile. Von allen Claude-Modellen akzeptiert.
  • Claude API Version: die Version der Anthropic-API. Ändern Sie sie nur, wenn Sie wissen, was Sie tun.

Sie können diese Optionen auch für einen einzelnen Prompt festlegen, auf der Seite der benutzerdefinierten Prompts, sowie für jede KI-Funktion (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), mit der Schaltfläche Advanced options ihrer spezifischen Verbindung.

Tipps

  • Claude-Modelle verarbeiten dank ihres großen Kontextfensters auch große Textmengen gut, nützlich bei langen E-Mail-Verläufen.
  • Claude antwortet eher ausführlich. Wenn Sie kürzere Antworten bevorzugen, fügen Sie Anweisungen wie "Fasse dich kurz" direkt in Ihre Prompts, in einen benutzerdefinierten Prompt oder in den System Prompt ein.
  • Neue Claude-Modelle funktionieren, sobald sie in der Liste erscheinen. Lehnt ein Modell eine der Optionen ab, wiederholt ThunderAI die Anfrage automatisch einmal ohne sie.
  • Wird das Rate-Limit von Anthropic überschritten, während ThunderAI mehrere E-Mails verarbeitet (Add Tags, Spam Filter, Summarize, Translate), stoppt die Verarbeitung von selbst und meldet, wie viele Nachrichten verarbeitet wurden.
  • Überwachen Sie Ihre API-Nutzung und Kosten unter console.anthropic.com.

Fehlerbehebung

Fehler "Authentication failed — check your API key" oder "Invalid API key"

Prüfen Sie, ob der Schlüssel korrekt kopiert wurde. Erzeugen Sie bei Bedarf in der Anthropic-Konsole einen neuen.

Das Popup fragt nach einer Berechtigung, statt die Prompts anzuzeigen

Die Berechtigung für anthropic.com wurde noch nicht erteilt, und ohne sie kann ThunderAI die Claude API nicht erreichen. Klicken Sie auf die Meldung im Popup: Die Willkommensseite von ThunderAI öffnet sich. Klicken Sie dort auf dieselbe Meldung und bestätigen Sie die Anfrage von Thunderbird. Sie können sie auch in Schritt 4 erteilen.

Fehler "Credit balance too low"

Laden Sie Ihr Anthropic-Konto auf unter console.anthropic.com/settings/billing.

In der Liste erscheinen keine Modelle

Wenn Sie "You have denied the optional permission needed to fetch models for this integration" sehen, klicken Sie erneut auf Update list und bestätigen Sie die Berechtigungsanfrage von Thunderbird. Andernfalls prüfen Sie, ob Ihr API-Schlüssel gültig ist.
