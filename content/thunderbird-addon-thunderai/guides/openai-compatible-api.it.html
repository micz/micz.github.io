L'integrazione con OpenAI Compatible API ti consente di connettere ThunderAI a qualsiasi server che segua il formato API di OpenAI.
Questo include server locali come LM Studio, servizi ospitati come DeepSeek, Grok, Mistral AI, OpenRouter e Perplexity, nonché qualsiasi endpoint personalizzato o self-hosted.

Configurazioni predefinite

ThunderAI include preset già pronti per i servizi OpenAI-compatibili più diffusi. Se utilizzi uno di questi, seleziona il preset e inserisci solo la tua chiave API:

Preset Note
DeepSeek API Veloce ed economico, modelli di ragionamento avanzati
Grok API Modelli Grok di xAI
Mistral API Modelli ospitati da Mistral AI
OpenRouter API Accedi a molti provider tramite un'unica chiave API
Perplexity API Include modelli con ricerca web integrata

Configurazione

Il modo più rapido è il Setup Wizard: aprilo dalla pagina di benvenuto di ThunderAI, dal popup della barra degli strumenti o dalla pagina delle impostazioni, scegli OpenAI Compatible API, seleziona un servizio o inserisci l'indirizzo del tuo server, scegli un modello e testa la connessione. Poi il wizard ti permette di attivare le funzioni AI che ti servono.
Per configurarla a mano, segui i passi qui sotto.

1. Apri le impostazioni di ThunderAI

In Thunderbird, vai su Strumenti → Componenti aggiuntivi e temi → ThunderAI → Preferenze.

2. Seleziona l'integrazione OpenAI Compatible API

Nel pannello Connection Settings, scegli OpenAI Compatible API nel menu a tendina Connection Type.

3a. Usare un preset

Se il tuo provider ha un preset, selezionalo in Available Services e conferma. ThunderAI compila l'indirizzo del server, l'impostazione "v1" e il nome della chat, e svuota l'elenco dei modelli. Inserisci la chiave API e prosegui dal passo 5.

3b. Configurazione manuale

Se il tuo provider non è nell'elenco, scegli Custom e configuralo a mano:

  • Host Address: l'URL di base del tuo server, senza /v1. Per LM Studio in locale di solito è http://localhost:1234. Puoi inserire anche l'indirizzo di un server remoto.
  • Keep the "v1" compatibility (nelle opzioni avanzate, attiva di default): ThunderAI aggiunge /v1 all'indirizzo, come in http://localhost:1234/v1/chat/completions. Disattivala se gli endpoint del tuo provider non hanno il segmento /v1.

4. Inserisci la chiave API (se richiesta)

Inseriscila nel campo OpenAI Comp API Key, che è facoltativo. I server locali come LM Studio di solito non richiedono una chiave API, quindi puoi lasciarlo vuoto. I servizi ospitati richiedono una chiave valida.

5. Scegli un modello

Clicca su Update list accanto a OpenAI Compatible API Models, poi seleziona il modello dall'elenco.

Se il server non fornisce l'elenco dei modelli, clicca su Add manually e scrivi il nome del modello indicato dal tuo provider. Clear list svuota l'elenco.

6. Testa la connessione

Le impostazioni vengono salvate appena le modifichi: non c'è un pulsante Salva.
Clicca su Test now nella barra sotto le impostazioni di connessione e accetta la richiesta di permesso di Thunderbird, se compare. Se è tutto a posto, la barra mostra "Connected — OpenAI Compatible API reachable". Poi apri una qualsiasi email, clicca sul pulsante ThunderAI nella barra degli strumenti e lancia un prompt.

Opzioni avanzate

Clicca su Advanced options nel pannello Connection Settings per mostrare queste impostazioni:

  • Keep the "v1" compatibility: vedi il passo 3b.
  • Chat Name: il nome con cui l'AI compare nella finestra di chat di ThunderAI.
  • Temperature: tra 0 e 2. Valori più alti rendono l'output più casuale, valori più bassi più mirato.
  • Extra body data: parametri aggiuntivi in formato JSON, per le opzioni che il servizio supporta ma ThunderAI non mostra, ad es. {"top_p": 0.9}, o {"chat_template_kwargs": {"thinking": false}} per disattivare il ragionamento sui server che lo supportano.

Puoi impostare queste opzioni anche sul singolo prompt, nella pagina dei prompt personalizzati, e su ciascuna funzione AI (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con il pulsante Advanced options della sua connessione specifica.

LM Studio — configurazione rapida

LM Studio offre un server locale con API compatibile OpenAI e un'interfaccia grafica per scaricare e gestire i modelli.

  1. Scarica e installa LM Studio da lmstudio.ai
  2. Scarica un modello a tua scelta dal catalogo di LM Studio
  3. In LM Studio, avvia il server locale
  4. In ThunderAI, scegli Custom, imposta l'Host Address su http://localhost:1234, lascia attiva la compatibilità "v1", lascia vuota la chiave API e seleziona il modello

Suggerimenti

  • OpenRouter è un'ottima scelta se vuoi accedere a molti modelli diversi (tra cui Claude, Gemini e Mistral) con un'unica chiave API e un unico account di fatturazione.
  • Con i server locali le prestazioni dipendono dal tuo hardware — consulta la guida Ollama per i consigli sull'hardware.
  • Se le richieste falliscono con un errore CORS e non puoi modificare la configurazione del server, clicca su Give permission to the current host nelle impostazioni di ThunderAI (sotto "Problems setting CORS?"). Per un server su localhost o 127.0.0.1, Thunderbird chiede l'accesso a tutti i siti (<all_urls>).
  • Se durante l'elaborazione di più email (Add Tags, Spam Filter, Summarize, Translate) si supera il limite di richieste o la quota del servizio, l'elaborazione si ferma da sola e ti dice quanti messaggi sono stati elaborati.

Risoluzione dei problemi

"Connection refused" su un server locale

Assicurati che il server locale (ad es. LM Studio) sia effettivamente in esecuzione e che l'Host Address in ThunderAI corrisponda alla porta su cui è in ascolto.

Errore "401 Unauthorized"

Controlla la chiave API. Per i server locali che non richiedono una chiave, prova a inserire un valore fittizio come none. Alcuni server rifiutano il campo vuoto.

Elenco dei modelli vuoto

Clicca su Add manually e scrivi il nome del modello indicato dalla documentazione del provider o del server.

"404 Not Found", o errori causati dal "v1" nell'URL

Verifica che l'Host Address non finisca con /v1, perché ThunderAI lo aggiunge quando Keep the "v1" compatibility è attiva. Se gli endpoint del tuo provider non hanno il segmento /v1, disattiva questa opzione.
