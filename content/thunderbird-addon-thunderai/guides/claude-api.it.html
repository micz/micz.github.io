L'integrazione con la Claude API connette ThunderAI ai modelli AI Claude di Anthropic.
Claude è noto per produrre risposte accurate e ben strutturate, gestendo ottimamente i documenti lunghi — ideale per leggere e comporre email dettagliate.

Chiave API richiesta Opzione gratuita Ideale per
Sì No (pagamento a consumo) Analisi dettagliate, email lunghe, scrittura strutturata

Prerequisiti

  • Un account Anthropic con accesso alle API
  • Una chiave Claude API valida
  • Thunderbird con ThunderAI installato

Ottenere una chiave API

  1. Vai su console.anthropic.com/settings/keys
  2. Clicca su Create Key
  3. Assegnagli un nome e copia subito la chiave: non verrà mostrata di nuovo

Configurazione

Il modo più rapido è il Setup Wizard: aprilo dalla pagina di benvenuto di ThunderAI, dal popup della barra degli strumenti o dalla pagina delle impostazioni, scegli Claude API, incolla la chiave API, scegli un modello e testa la connessione. Poi il wizard ti permette di attivare le funzioni AI che ti servono.
Per configurarla a mano, segui i passi qui sotto.

1. Apri le impostazioni di ThunderAI

In Thunderbird, vai su Strumenti → Componenti aggiuntivi e temi → ThunderAI → Preferenze.

2. Seleziona l'integrazione Claude API

Nel pannello Connection Settings, scegli Claude API nel menu a tendina Connection Type.

3. Inserisci la chiave API

Incolla la chiave API nel campo Claude API Key. La chiave è memorizzata localmente in Thunderbird e viene inviata solo ai server di Anthropic.

4. Scegli un modello

Clicca su Update list accanto a Claude Models. La prima volta Thunderbird chiede il permesso di accedere a anthropic.com: accettalo, altrimenti ThunderAI non può raggiungere la Claude API. Poi seleziona dall'elenco il modello che vuoi usare.

Questo permesso è opzionale e serve solo a comunicare con i server API di Anthropic. ThunderAI non raccoglie alcun dato.

5. Testa la connessione

Le impostazioni vengono salvate appena le modifichi: non c'è un pulsante Salva.
Clicca su Test now nella barra sotto le impostazioni di connessione. Se è tutto a posto, mostra "Connected — Claude API reachable". Poi apri una qualsiasi email, clicca sul pulsante ThunderAI nella barra degli strumenti e lancia un prompt.

Opzioni avanzate

Clicca su Advanced options nel pannello Connection Settings per mostrare le impostazioni qui sotto. Si adattano al modello selezionato: un'impostazione che il modello non accetta viene disattivata, con una nota che spiega il motivo, e non viene inviata. Il valore salvato viene mantenuto, nel caso torni a un altro modello.

  • System Prompt: istruzioni e contesto inviati al modello con ogni prompt.
  • Max Tokens: la lunghezza massima della risposta.
  • Effort: quanto ragionamento il modello dedica a una richiesta. I livelli più alti danno risposte migliori sui compiti complessi, ma costano più token e richiedono più tempo. Lascialo su Default per lasciar decidere all'API. I modelli Claude più vecchi non lo supportano.
  • Extended thinking budget (tokens): per i modelli più vecchi, il numero massimo di token che il modello può usare per ragionare. 0 disattiva il ragionamento esteso. Deve essere almeno 1024 e minore di Max Tokens: altrimenti le impostazioni mostrano un avviso e il valore non viene inviato.
  • Temperature (0.0–1.0), Top P e Top K: quanto la risposta è casuale o mirata. I modelli Claude più recenti non li accettano: usa invece Effort.
  • Stop sequences: testi che fanno smettere di scrivere il modello, uno per riga. Accettate da tutti i modelli Claude.
  • Claude API Version: la versione dell'API di Anthropic. Non cambiarla se non sai cosa stai facendo.

Puoi impostare queste opzioni anche sul singolo prompt, nella pagina dei prompt personalizzati, e su ciascuna funzione AI (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con il pulsante Advanced options della sua connessione specifica.

Suggerimenti

  • I modelli Claude gestiscono bene grandi quantità di testo grazie alla loro ampia finestra di contesto, utile per elaborare lunghi thread di email.
  • Claude tende a dare risposte esaurienti. Se preferisci risposte più brevi, aggiungi istruzioni come "Sii conciso" direttamente nei prompt, in un prompt personalizzato o nel System Prompt.
  • I nuovi modelli Claude funzionano appena compaiono nell'elenco. Se un modello rifiuta una delle opzioni, ThunderAI ripete automaticamente la richiesta una volta senza quell'opzione.
  • Se durante l'elaborazione di più email (Add Tags, Spam Filter, Summarize, Translate) si supera il limite di richieste di Anthropic, l'elaborazione si ferma da sola e ti dice quanti messaggi sono stati elaborati.
  • Controlla l'utilizzo e i costi dell'API su console.anthropic.com.

Risoluzione dei problemi

Errore "Authentication failed — check your API key" o "Invalid API key"

Verifica di aver copiato correttamente la chiave. Se necessario, generane una nuova dalla console di Anthropic.

Il popup chiede un permesso invece di mostrare i prompt

Il permesso per anthropic.com non è ancora stato concesso, e senza di esso ThunderAI non può raggiungere la Claude API. Clicca sul messaggio nel popup: si apre la pagina di benvenuto di ThunderAI. Clicca lì sullo stesso messaggio e accetta la richiesta di Thunderbird. Puoi concederlo anche dal passo 4.

Errore "Credit balance too low"

Aggiungi crediti al tuo account Anthropic su console.anthropic.com/settings/billing.

Nell'elenco non compare nessun modello

Se vedi "You have denied the optional permission needed to fetch models for this integration", clicca di nuovo su Update list e accetta la richiesta di permesso di Thunderbird. Altrimenti verifica che la chiave API sia valida.
