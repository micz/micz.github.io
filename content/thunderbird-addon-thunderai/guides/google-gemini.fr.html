L'intégration Google Gemini connecte ThunderAI aux modèles AI Gemini de Google via l'API Gemini.
Elle inclut la prise en charge d'options avancées telles que la System Instruction et le Thinking Budget, utiles pour les utilisateurs qui souhaitent un contrôle plus fin du comportement du modèle.

Clé API requise Option gratuite Idéal pour
Oui Oui (niveau gratuit généreux disponible) Les utilisateurs de l'écosystème Google ou souhaitant une option API gratuite

Prérequis

  • Un compte Google
  • Une clé Gemini API (niveau gratuit disponible)
  • Thunderbird avec ThunderAI installé

Obtenir une clé API

  1. Accédez à aistudio.google.com/apikey
  2. Cliquez sur Create API key
  3. Sélectionnez un projet Google Cloud existant ou créez-en un nouveau
  4. Copiez la clé API générée

L'API Gemini propose un niveau gratuit avec des limites généreuses, adapté à un usage personnel. Des niveaux payants sont disponibles si vous avez besoin d'un débit plus élevé.

Configuration

Le plus rapide est le Setup Wizard : ouvrez-le depuis la page d'accueil de ThunderAI, le popup de la barre d'outils ou la page des paramètres, choisissez Google Gemini API, collez votre clé API, choisissez un modèle et testez la connexion. L'assistant vous permet ensuite d'activer les fonctions IA souhaitées.
Pour une configuration manuelle, suivez les étapes ci-dessous.

1. Ouvrir les paramètres de ThunderAI

Dans Thunderbird, accédez à Outils → Modules complémentaires et thèmes → ThunderAI → Préférences.

2. Sélectionner l'intégration Google Gemini

Dans le panneau Connection Settings, choisissez Google Gemini API dans la liste déroulante Connection Type.

3. Saisir votre clé API

Collez votre clé API dans le champ API Key. La clé est stockée localement dans Thunderbird et n'est envoyée qu'aux serveurs de Google.

4. Choisir un modèle

Cliquez sur Update list à côté de Google Gemini API Models, puis sélectionnez le modèle à utiliser dans la liste.

5. Tester la connexion

Les paramètres sont enregistrés dès que vous les modifiez : il n'y a pas de bouton Enregistrer.
Cliquez sur Test now dans la barre sous les paramètres de connexion. Si Thunderbird demande la permission d'accéder à generativelanguage.googleapis.com, acceptez-la. Si tout va bien, la barre affiche "Connected — Google Gemini API reachable". Ouvrez ensuite n'importe quel e-mail, cliquez sur le bouton ThunderAI dans la barre d'outils et lancez un prompt.

Options avancées

Cliquez sur Advanced options dans le panneau Connection Settings pour afficher les paramètres ci-dessous. Laissez un champ vide pour que le modèle utilise sa valeur par défaut.

  • System Instruction : un contexte permanent pour tous vos prompts, par exemple pour toujours répondre de façon formelle, dans une langue précise ou dans un certain rôle.
  • Thinking Budget : combien de tokens le modèle peut utiliser pour raisonner avant de répondre. Saisissez 0 pour désactiver le raisonnement, ou -1 pour un raisonnement dynamique. Laissez-le vide si le modèle ne prend pas en charge le raisonnement.
  • Temperature (0.0–2.0), Top P et Top K : à quel point la réponse est aléatoire ou ciblée. Tous les modèles ne prennent pas en charge Top K.
  • Max output tokens : la longueur maximale de la réponse. Vide ou 0 laisse le modèle décider.
  • Extra body data : paramètres supplémentaires pour l'API Gemini, sous forme d'objet JSON, pour les options que ThunderAI n'affiche pas, par ex. {"generationConfig": {"seed": 42}}. Les clés à l'intérieur de generationConfig sont fusionnées avec celles générées par ThunderAI.

Vous pouvez aussi définir ces options pour un seul prompt, dans la page des prompts personnalisés, et pour chaque fonction IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), avec le bouton Advanced options de sa connexion spécifique.

Conseils

  • Le niveau gratuit a des limites de requêtes par minute et par jour, généralement suffisantes pour un usage personnel. Consultez les limites actuelles dans Google AI Studio.
  • Si la limite est atteinte pendant que ThunderAI traite plusieurs e-mails (Add Tags, Spam Filter, Summarize, Translate), le traitement s'arrête de lui-même et indique combien de messages ont été traités et, quand Google le précise, combien de temps attendre.
  • La System Instruction est particulièrement utile si vous souhaitez définir des règles générales pour votre assistant e-mail.

Dépannage

Erreur "Authentication failed — check your API key" ou "API key not valid"

Vérifiez que la clé a été copiée correctement. Si nécessaire, générez-en une nouvelle depuis AI Studio.

"Model not found" ou liste de modèles vide

Assurez-vous que votre clé API a accès aux modèles Gemini. Certaines clés créées dans des projets Google Cloud restreints peuvent avoir un accès limité aux modèles.

Les requêtes échouent après la modification des options avancées

Certains modèles n'acceptent pas toutes les options (par exemple Top K, ou un Thinking Budget sur un modèle sans raisonnement). Videz l'option et réessayez.
