La integración con la Claude API conecta ThunderAI con los modelos de IA Claude de Anthropic.
Claude es conocido por producir respuestas cuidadosas y bien estructuradas, y por manejar eficazmente documentos largos — ideal para leer y redactar correos electrónicos detallados.

Clave de API requerida Opción gratuita Ideal para
Sí No (facturación por uso) Análisis detallado, correos largos, escritura estructurada

Requisitos previos

  • Una cuenta de Anthropic con acceso a la API
  • Una clave de API de Claude válida
  • Thunderbird con ThunderAI instalado

Cómo obtener una clave de API

  1. Ve a console.anthropic.com/settings/keys
  2. Haz clic en Create Key
  3. Dale un nombre y copia la clave inmediatamente; no se mostrará de nuevo

Configuración

Lo más rápido es el Setup Wizard: ábrelo desde la página de bienvenida de ThunderAI, el popup de la barra de herramientas o la página de ajustes, elige Claude API, pega tu clave de API, elige un modelo y prueba la conexión. Después el asistente te permite activar las funciones de IA que quieras.
Para configurarla a mano, sigue los pasos de abajo.

1. Abre los ajustes de ThunderAI

En Thunderbird, ve a Herramientas → Complementos y temas → ThunderAI → Preferencias.

2. Selecciona la integración Claude API

En el panel Connection Settings, elige Claude API en el desplegable Connection Type.

3. Introduce tu clave de API

Pega tu clave de API en el campo Claude API Key. La clave se guarda localmente en Thunderbird y solo se envía a los servidores de Anthropic.

4. Elige un modelo

Haz clic en Update list junto a Claude Models. La primera vez, Thunderbird pide permiso para acceder a anthropic.com: acéptalo, o ThunderAI no podrá conectar con la Claude API. Después selecciona en la lista el modelo que quieres usar.

Este permiso es opcional y solo sirve para comunicarse con los servidores de la API de Anthropic. ThunderAI no recopila ningún dato.

5. Prueba la conexión

Los ajustes se guardan en cuanto los cambias: no hay botón Guardar.
Haz clic en Test now en la barra bajo los ajustes de conexión. Si todo está bien, muestra "Connected — Claude API reachable". Después abre cualquier correo, haz clic en el botón de ThunderAI en la barra de herramientas y ejecuta un prompt.

Opciones avanzadas

Haz clic en Advanced options en el panel Connection Settings para mostrar los ajustes de abajo. Se adaptan al modelo seleccionado: un ajuste que el modelo no acepta se desactiva, con una nota que explica el motivo, y no se envía. El valor guardado se conserva, por si vuelves a otro modelo.

  • System Prompt: instrucciones y contexto que se envían al modelo con cada prompt.
  • Max Tokens: la longitud máxima de la respuesta.
  • Effort: cuánto razonamiento dedica el modelo a una solicitud. Los niveles más altos dan mejores respuestas en tareas complejas, pero cuestan más tokens y tardan más. Déjalo en Default para que decida la API. Los modelos Claude más antiguos no lo admiten.
  • Extended thinking budget (tokens): en los modelos más antiguos, el número máximo de tokens que el modelo puede dedicar a pensar. 0 desactiva el pensamiento extendido. Debe ser al menos 1024 y menor que Max Tokens: si no, los ajustes muestran un aviso y el valor no se envía.
  • Temperature (0.0–1.0), Top P y Top K: cuán aleatoria o precisa es la respuesta. Los modelos Claude más recientes no los aceptan: usa Effort en su lugar.
  • Stop sequences: textos que hacen que el modelo deje de escribir, uno por línea. Las aceptan todos los modelos Claude.
  • Claude API Version: la versión de la API de Anthropic. No la cambies si no sabes lo que haces.

También puedes definir estas opciones en un solo prompt, en la página de prompts personalizados, y en cada función de IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con el botón Advanced options de su conexión específica.

Consejos

  • Los modelos Claude manejan bien grandes cantidades de texto gracias a su amplia ventana de contexto, útil para procesar hilos de correo largos.
  • Claude tiende a dar respuestas detalladas. Si prefieres respuestas más cortas, añade instrucciones como "Sé conciso" directamente en tus prompts, en un prompt personalizado o en el System Prompt.
  • Los nuevos modelos Claude funcionan en cuanto aparecen en la lista. Si un modelo rechaza una de las opciones, ThunderAI repite automáticamente la solicitud una vez sin ella.
  • Si se supera el límite de solicitudes de Anthropic mientras ThunderAI procesa varios correos (Add Tags, Spam Filter, Summarize, Translate), el procesamiento se detiene solo e indica cuántos mensajes se procesaron.
  • Controla el uso y los costes de la API en console.anthropic.com.

Solución de problemas

Error "Authentication failed — check your API key" o "Invalid API key"

Comprueba que la clave se copió correctamente. Si es necesario, genera una nueva desde la consola de Anthropic.

El popup pide un permiso en lugar de mostrar los prompts

Aún no se ha concedido el permiso para anthropic.com, y sin él ThunderAI no puede conectar con la Claude API. Haz clic en el mensaje del popup: se abre la página de bienvenida de ThunderAI. Haz clic allí en el mismo mensaje y acepta la solicitud de Thunderbird. También puedes concederlo desde el paso 4.

Error "Credit balance too low"

Añade créditos a tu cuenta de Anthropic en console.anthropic.com/settings/billing.

No aparece ningún modelo en la lista

Si ves "You have denied the optional permission needed to fetch models for this integration", haz clic de nuevo en Update list y acepta la solicitud de permiso de Thunderbird. Si no, comprueba que tu clave de API es válida.
