L'intégration Claude API connecte ThunderAI aux modèles AI Claude d'Anthropic.
Claude est reconnu pour produire des réponses soignées et bien structurées, et pour gérer efficacement les longs documents — idéal pour lire et rédiger des e-mails détaillés.

Clé API requise Option gratuite Idéal pour
Oui Non (facturation à l'usage) Analyses détaillées, e-mails longs, rédaction structurée

Prérequis

  • Un compte Anthropic avec accès à l'API
  • Une clé Claude API valide
  • Thunderbird avec ThunderAI installé

Obtenir une clé API

  1. Accédez à console.anthropic.com/settings/keys
  2. Cliquez sur Create Key
  3. Donnez-lui un nom et copiez la clé immédiatement, elle ne sera plus affichée

Configuration

Le plus rapide est le Setup Wizard : ouvrez-le depuis la page d'accueil de ThunderAI, le popup de la barre d'outils ou la page des paramètres, choisissez Claude API, collez votre clé API, choisissez un modèle et testez la connexion. L'assistant vous permet ensuite d'activer les fonctions IA souhaitées.
Pour une configuration manuelle, suivez les étapes ci-dessous.

1. Ouvrir les paramètres de ThunderAI

Dans Thunderbird, accédez à Outils → Modules complémentaires et thèmes → ThunderAI → Préférences.

2. Sélectionner l'intégration Claude API

Dans le panneau Connection Settings, choisissez Claude API dans la liste déroulante Connection Type.

3. Saisir votre clé API

Collez votre clé API dans le champ Claude API Key. La clé est stockée localement dans Thunderbird et n'est envoyée qu'aux serveurs d'Anthropic.

4. Choisir un modèle

Cliquez sur Update list à côté de Claude Models. La première fois, Thunderbird demande la permission d'accéder à anthropic.com : acceptez-la, sinon ThunderAI ne peut pas joindre la Claude API. Sélectionnez ensuite le modèle à utiliser dans la liste.

Cette permission est optionnelle et sert uniquement à communiquer avec les serveurs API d'Anthropic. ThunderAI ne collecte aucune donnée.

5. Tester la connexion

Les paramètres sont enregistrés dès que vous les modifiez : il n'y a pas de bouton Enregistrer.
Cliquez sur Test now dans la barre sous les paramètres de connexion. Si tout va bien, elle affiche "Connected — Claude API reachable". Ouvrez ensuite n'importe quel e-mail, cliquez sur le bouton ThunderAI dans la barre d'outils et lancez un prompt.

Options avancées

Cliquez sur Advanced options dans le panneau Connection Settings pour afficher les paramètres ci-dessous. Ils s'adaptent au modèle sélectionné : un paramètre que le modèle n'accepte pas est désactivé, avec une note qui en explique la raison, et n'est pas envoyé. La valeur enregistrée est conservée, au cas où vous reviendriez à un autre modèle.

  • System Prompt : instructions et contexte envoyés au modèle avec chaque prompt.
  • Max Tokens : la longueur maximale de la réponse.
  • Effort : combien de raisonnement le modèle consacre à une requête. Les niveaux plus élevés donnent de meilleures réponses sur les tâches complexes, mais coûtent plus de tokens et prennent plus de temps. Laissez Default pour laisser l'API décider. Les anciens modèles Claude ne le prennent pas en charge.
  • Extended thinking budget (tokens) : pour les anciens modèles, le nombre maximal de tokens que le modèle peut consacrer à la réflexion. 0 désactive la réflexion étendue. La valeur doit être d'au moins 1024 et inférieure à Max Tokens : sinon les paramètres affichent un avertissement et la valeur n'est pas envoyée.
  • Temperature (0.0–1.0), Top P et Top K : à quel point la réponse est aléatoire ou ciblée. Les modèles Claude récents ne les acceptent pas : utilisez plutôt Effort.
  • Stop sequences : textes qui font arrêter le modèle d'écrire, un par ligne. Acceptées par tous les modèles Claude.
  • Claude API Version : la version de l'API d'Anthropic. Ne la modifiez pas sans savoir ce que vous faites.

Vous pouvez aussi définir ces options pour un seul prompt, dans la page des prompts personnalisés, et pour chaque fonction IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), avec le bouton Advanced options de sa connexion spécifique.

Conseils

  • Les modèles Claude gèrent bien de grandes quantités de texte grâce à leur large fenêtre de contexte, utile pour traiter de longs fils d'e-mails.
  • Claude a tendance à donner des réponses détaillées. Si vous préférez des réponses plus courtes, ajoutez des instructions comme "Sois concis" directement dans vos prompts, dans un prompt personnalisé ou dans le System Prompt.
  • Les nouveaux modèles Claude fonctionnent dès qu'ils apparaissent dans la liste. Si un modèle refuse l'une des options, ThunderAI répète automatiquement la requête une fois sans elle.
  • Si la limite de requêtes d'Anthropic est dépassée pendant que ThunderAI traite plusieurs e-mails (Add Tags, Spam Filter, Summarize, Translate), le traitement s'arrête de lui-même et indique combien de messages ont été traités.
  • Surveillez votre utilisation de l'API et vos coûts sur console.anthropic.com.

Dépannage

Erreur "Authentication failed — check your API key" ou "Invalid API key"

Vérifiez que la clé a été copiée correctement. Si nécessaire, générez-en une nouvelle depuis la console Anthropic.

Le popup demande une permission au lieu d'afficher les prompts

La permission pour anthropic.com n'a pas encore été accordée, et sans elle ThunderAI ne peut pas joindre la Claude API. Cliquez sur le message dans le popup : la page d'accueil de ThunderAI s'ouvre. Cliquez-y sur le même message et acceptez la demande de Thunderbird. Vous pouvez aussi l'accorder à l'étape 4.

Erreur "Credit balance too low"

Ajoutez des crédits à votre compte Anthropic sur console.anthropic.com/settings/billing.

Aucun modèle n'apparaît dans la liste

Si vous voyez "You have denied the optional permission needed to fetch models for this integration", cliquez de nouveau sur Update list et acceptez la demande de permission de Thunderbird. Sinon, vérifiez que votre clé API est valide.
