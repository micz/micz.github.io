ChatGPT Web Interface との連携を使うと、API キーなしで ThunderAI を利用できます。
ThunderAI がお客様に代わって ChatGPT のウェブサイトを直接操作するため、必要なのは無料の ChatGPT アカウントだけです。

API キー 無料オプション おすすめの用途
不要 あり（無料の ChatGPT アカウントでも可） 支払いの設定なしで、すぐに使い始めたい場合

前提条件

  • chatgpt.com の無料（または有料）アカウント
  • ThunderAI をインストールした Thunderbird

セットアップ

最も簡単な方法は Setup Wizard です。ThunderAI のウェルカムページ、ツールバーのポップアップ、または設定ページから開き、 ChatGPT Web Interface を選択してください。その後、手順 3 から進めます。
手動で設定する場合は、以下の手順をすべて行ってください。

1. ThunderAI の設定を開く

Thunderbird で ツール → アドオンとテーマ → ThunderAI → 設定 を開きます。

2. ChatGPT Web Interface を選択する

Connection Settings パネルで、Connection Type のドロップダウンから ChatGPT Web Interface を選択します。

3. 必要な権限を許可する

ThunderAI には chatgpt.com へのアクセス権限が必要です。この権限は設定ページではなく、ThunderAI のポップアップから求められます。

  1. ツールバーの ThunderAI ボタンをクリックします。権限が許可されていない間は、ポップアップにプロンプトの一覧の代わりに "To use the ChatGPT Web integration, you need to grant the required permission." と表示されます。
  2. そのメッセージをクリックすると、ThunderAI のウェルカムページが新しいタブで開きます。
  3. ウェルカムページの上部にある同じメッセージをクリックし、Thunderbird の権限リクエストを承認します。
  4. "Permission granted" と表示されたら、それをクリックしてタブを閉じます。

ChatGPT Web Interface を選択すると、設定ページ上部の Open the Welcome Page カードからもウェルカムページを開けます。 同じリクエストが表示されます。

この権限は任意であり、お客様に代わって ChatGPT のウェブサイトを操作するためだけに使用されます。ThunderAI がお客様のデータを収集または保存することはありません。

4. ChatGPT にログインする

この操作は一度だけ必要です。Thunderbird がセッションを維持します。
初めてプロンプトを使うと、ThunderAI が ChatGPT のウィンドウを開きます。ログインしていない場合はその旨が表示されるので、 そのウィンドウでご自分のアカウントにログインし、ウィンドウを閉じてから、もう一度プロンプトを実行してください。
そのウィンドウからログインできない場合は、ThunderAI の設定にある Open ChatGPT Tab ボタンを使ってください。 Thunderbird のタブで chatgpt.com が開くので、そこでログインできます。その後タブを閉じて、ThunderAI の利用に戻ります。

5. 連携をテストする

任意のメールを開き、ツールバーの ThunderAI ボタンをクリックして、プロンプト（例: Summarize）を選択します。ThunderAI が ChatGPT のウィンドウを開き、プロンプトを送信して、そこに回答を表示します。

詳細オプション

Connection Settings パネルの Advanced options をクリックすると、次の設定が表示されます。

  • ChatGPT Web Model: 使用するモデルです。空欄または無効な場合、ChatGPT は既定のモデルを使用します。無料の ChatGPT アカウントでは機能しません。
  • ChatGPT Web Project と ChatGPT Web Custom GPT: 常に使用する Project または Custom GPT です。 ChatGPT で Project（/g/PROJECT-ID-PROJECT-NAME/project）または Custom GPT（/g/CUSTOM-GPT-ID）を開いているときに、ブラウザーのアドレスバーから値をコピーしてください。カスタムプロンプトのページで、個々のプロンプトに設定することもできます。
  • ChatGPT Web temporary chat: 一時チャットを使用します。
  • Wait time for page load: ChatGPT のページの読み込みを ThunderAI が待つ時間（ミリ秒、既定値 1000）です。Project または Custom GPT を使用する場合は、1000 ms が加算されます。

Open ChatGPT Tab ボタンにも、設定したモデル、Project、Custom GPT が適用されます。

ヒントと既知の制限

  • 応答速度は ChatGPT のウェブサイトに依存し、変動することがあります。一般に、API 連携のほうが高速で安定しています。
  • 無料アカウントには、ChatGPT 自体の利用制限（レート制限、利用できるモデル）が適用されます。
  • ChatGPT がウェブサイトのレイアウトを変更すると、ThunderAI が更新されるまで連携が一時的に動作しなくなることがあります。既知の問題についてはステータスページをご確認ください。
  • 設定ページに表示される AI 機能（Add Tags、Spam Filter、Summarize、Translate、Calendar Event、Task）には API 連携が必要で、ChatGPT Web Interface では動作しません。 ChatGPT Web をメインの接続のままにして、これらの機能それぞれに、その設定ページで個別の API 接続を割り当てることができます。ツールバーのメニューから使うプロンプトは、引き続き ChatGPT Web で動作します。

トラブルシューティング

ポップアップにプロンプトではなく権限のリクエストが表示される

chatgpt.com の権限がまだ許可されていません。手順 3 をご覧ください。

ログインしていないと表示される、または応答が表示されない

ThunderAI が開いた ChatGPT のウィンドウで ChatGPT にログインし、ウィンドウを閉じてから再度お試しください。それでも解決しない場合は、ThunderAI の設定にある Open ChatGPT Tab ボタンで開いたタブからログインしてください。

"Could not locate the ChatGPT message box"

ThunderAI が ChatGPT のテキストボックスを見つけられませんでした。通常は ChatGPT のウェブサイトが変更された後に起こります。1 分以内に ChatGPT のテキストボックス内をクリックすると、ThunderAI が処理を続行します。毎回発生する場合は、ステータスページをご確認ください。

応答が遅い、またはタイムアウトする

通常は ChatGPT のウェブサイトの一時的な問題です。しばらく待ってから再度お試しいただくか、より安定した動作を求める場合は OpenAI API 連携への切り替えをご検討ください。
