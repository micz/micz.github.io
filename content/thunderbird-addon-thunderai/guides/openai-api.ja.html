OpenAI API 連携は、API キーを使って ThunderAI を OpenAI のサーバーに直接接続します。
ウェブインターフェースと比べて、より速く、より安定しており、使用するモデルを明示的に指定できます。

API キーが必要 無料オプション おすすめの用途
はい いいえ(従量課金) ChatGPT モデルへの安定した高速アクセス

前提条件

  • API アクセスが有効になっている OpenAI アカウント
  • 有効な API キー
  • ThunderAI がインストールされた Thunderbird

注意:OpenAI API の利用料金は、ChatGPT のサブスクリプションとは別に請求されます。ChatGPT Plus を契約していても、API アカウントにクレジットを追加する必要があります。

API キーの取得

  1. platform.openai.com/api-keys にアクセスします
  2. Create new secret key をクリックします
  3. 名前を付けて(例:"ThunderAI")、Create をクリックします
  4. キーはすぐにコピーしてください。二度と表示されません

セットアップ

最も手早いのは Setup Wizard を使う方法です。ThunderAI のウェルカムページ、ツールバーのポップアップ、 または設定ページから開き、ChatGPT OpenAI API を選んで、API キーを貼り付け、モデルを選んで 接続をテストします。その後、ウィザードで必要な AI 機能を有効にできます。
手動で設定する場合は、以下の手順に従ってください。

1. ThunderAI の設定を開く

Thunderbird で、ツール → アドオンとテーマ → ThunderAI → 設定 に移動します。

2. OpenAI API 連携を選択する

Connection Settings パネルで、Connection Type のドロップダウンから ChatGPT OpenAI API を選びます。

3. API キーを入力する

ChatGPT API Key 欄に API キーを貼り付けます。キーは Thunderbird 内にローカルに保存され、OpenAI のサーバー以外に送信されることはありません。

4. モデルを選ぶ

ChatGPT Models の横にある Update list をクリックします。初回は Thunderbird が openai.com へのアクセス許可を求めます。承認してください。承認しないと ThunderAI は OpenAI に接続できません。その後、一覧から使いたいモデルを選びます。

5. 接続をテストする

設定は変更するとすぐに保存されます。保存ボタンはありません。
接続設定の下にあるバーの Test now をクリックします。問題がなければ、 "Connected — ChatGPT OpenAI API reachable" と表示されます。その後、任意のメールを開き、ツールバーの ThunderAI ボタンをクリックしてプロンプトを実行してください。

詳細オプション

Connection Settings パネルの Advanced options をクリックすると、以下の設定が表示されます。 空欄または Default のままにすると、API に判断を任せます。 これらは選択したモデルに合わせて変わります。モデルが受け付けない設定は無効になり、その理由を説明する注記が表示されます。 保存された値は、別のモデルに戻したときのために保持されます。

  • Temperature と Top P:回答のランダムさ、または的確さの度合いです。推論モデルはこれらを受け付けません。代わりに Reasoning effort を使ってください。
  • Reasoning effort と Reasoning summary:モデルがどれだけ推論するか、またチャットに推論の要約を表示するかどうかです。推論モデルのみが対象です。
  • Verbosity:回答の長さと詳しさです。対応しているモデルで使用できます。
  • Max output tokens:回答の最大の長さです。
  • Developer Messages:各プロンプトと一緒にモデルへ送信される指示とコンテキストです。
  • Output format:プレーンテキスト(既定)、JSON オブジェクト、またはご自身で入力したスキーマに従う JSON です。
  • Truncation、Service tier、Prompt cache key、Safety identifier、 Include encrypted reasoning:OpenAI へのリクエストのオプションで、 OpenAI API リファレンスで説明されています。
  • Use storage:オンにすると、OpenAI がチャットを保存します。
  • Extra body data:ThunderAI に表示されないオプション用の追加パラメーターを JSON オブジェクトで指定します。

これらのオプションは、カスタムプロンプトのページで個々のプロンプトに設定することも、各 AI 機能(Add Tags、Spam Filter、 Summarize、Translate、Calendar Event、Task)の個別接続にある Advanced options ボタンから設定することもできます。

ヒント

  • API の利用量はトークン単位で計測されます。メールは通常短いため、費用はたいていごくわずかです。利用状況は platform.openai.com/usage で確認できます。
  • OpenAI は定期的に新しいモデルを追加しています。Update list をクリックすると、最新のモデルを確認できます。
  • ThunderAI が複数のメールを処理している間(Add Tags、Spam Filter、Summarize、Translate)に OpenAI のレート制限やクォータを超えた場合、処理は自動的に停止し、処理済みのメッセージ数が表示されます。

トラブルシューティング

"Authentication failed — check your API key" または "Invalid API key" エラー

キーが正しくコピーされているか、余分な空白がないかを確認してください。それでもキーが使えない場合は、OpenAI のプラットフォームで新しいキーを生成してください。

"You exceeded your current quota" エラー

OpenAI の API アカウントのクレジットが不足しています。platform.openai.com/settings/organization/billing でクレジットを追加してください。

一覧にモデルが表示されない

"You have denied the optional permission needed to fetch models for this integration" と表示された場合は、もう一度 Update list をクリックし、Thunderbird の許可リクエストを承認してください。それ以外の場合は、API キーが有効であることと、インターネット接続を確認してください。

ポップアップにプロンプトではなく許可の要求が表示される

openai.com へのアクセス許可がまだ与えられていません。ポップアップのメッセージをクリックすると、ThunderAI のウェルカムページが開きます。 そこで同じメッセージをクリックし、Thunderbird のリクエストを承認してください。手順 4 から許可を与えることもできます。
