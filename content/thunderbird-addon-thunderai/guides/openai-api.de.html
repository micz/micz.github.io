Die Integration mit der OpenAI API verbindet ThunderAI direkt über einen API-Schlüssel mit den OpenAI-Servern.
Im Vergleich zur Web-Oberfläche ist sie schneller, zuverlässiger und gibt Ihnen die explizite Kontrolle darüber, welches Modell Sie verwenden.

API-Schlüssel erforderlich Kostenlose Option Geeignet für
Ja Nein (nutzungsbasierte Abrechnung) Stabiler, schneller Zugriff auf ChatGPT-Modelle

Voraussetzungen

  • Ein OpenAI-Konto mit aktiviertem API-Zugang
  • Ein gültiger API-Schlüssel
  • Thunderbird mit installiertem ThunderAI

Hinweis: Die Nutzung der OpenAI API wird separat von einem ChatGPT-Abonnement abgerechnet. Auch wenn Sie ChatGPT Plus haben, müssen Sie Ihrem API-Konto dennoch Guthaben hinzufügen.

API-Schlüssel erhalten

  1. Gehen Sie zu platform.openai.com/api-keys
  2. Klicken Sie auf Create new secret key
  3. Geben Sie ihm einen Namen (z. B. „ThunderAI") und klicken Sie auf Create
  4. Kopieren Sie den Schlüssel sofort — er wird nicht noch einmal angezeigt

Einrichtung

Am schnellsten geht es mit dem Setup Wizard: Öffnen Sie ihn über die Willkommensseite von ThunderAI, das Popup in der Symbolleiste oder die Einstellungsseite, wählen Sie ChatGPT OpenAI API, fügen Sie Ihren API-Schlüssel ein, wählen Sie ein Modell und testen Sie die Verbindung. Anschließend können Sie im Wizard die gewünschten KI-Funktionen aktivieren.
Für die manuelle Einrichtung folgen Sie den Schritten unten.

1. ThunderAI-Einstellungen öffnen

Gehen Sie in Thunderbird zu Extras → Add-ons und Themes → ThunderAI → Einstellungen.

2. OpenAI-API-Integration auswählen

Wählen Sie im Bereich Connection Settings im Dropdown Connection Type die Option ChatGPT OpenAI API.

3. API-Schlüssel eingeben

Fügen Sie Ihren API-Schlüssel in das Feld ChatGPT API Key ein. Der Schlüssel wird lokal in Thunderbird gespeichert und nur an die Server von OpenAI gesendet.

4. Modell auswählen

Klicken Sie neben ChatGPT Models auf Update list. Beim ersten Mal fragt Thunderbird nach der Berechtigung, auf openai.com zuzugreifen: Bestätigen Sie sie, sonst kann ThunderAI OpenAI nicht erreichen. Wählen Sie dann das gewünschte Modell aus der Liste.

5. Verbindung testen

Einstellungen werden gespeichert, sobald Sie sie ändern: Es gibt keine Speichern-Schaltfläche.
Klicken Sie in der Leiste unter den Verbindungseinstellungen auf Test now. Wenn alles in Ordnung ist, erscheint "Connected — ChatGPT OpenAI API reachable". Öffnen Sie dann eine beliebige E-Mail, klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste und führen Sie einen Prompt aus.

Erweiterte Optionen

Klicken Sie im Bereich Connection Settings auf Advanced options, um die folgenden Einstellungen anzuzeigen. Lassen Sie sie leer oder auf Default, damit die API entscheidet. Sie passen sich an das ausgewählte Modell an: Eine Einstellung, die das Modell nicht akzeptiert, wird deaktiviert, mit einem Hinweis auf den Grund. Der gespeicherte Wert bleibt erhalten, falls Sie zu einem anderen Modell zurückwechseln.

  • Temperature und Top P: wie zufällig oder fokussiert die Antwort ist. Die Reasoning-Modelle akzeptieren sie nicht: Verwenden Sie stattdessen Reasoning effort.
  • Reasoning effort und Reasoning summary: wie viel das Modell nachdenkt und ob im Chat eine Zusammenfassung seiner Überlegungen angezeigt wird. Nur für Reasoning-Modelle.
  • Verbosity: wie lang und ausführlich die Antwort ist, bei Modellen, die das unterstützen.
  • Max output tokens: die maximale Länge der Antwort.
  • Developer Messages: Anweisungen und Kontext, die mit jedem Prompt an das Modell gesendet werden.
  • Output format: reiner Text (Standard), ein JSON-Objekt oder JSON nach einem von Ihnen eingegebenen Schema.
  • Truncation, Service tier, Prompt cache key, Safety identifier und Include encrypted reasoning: Optionen der OpenAI-Anfragen, beschrieben in der OpenAI-API-Referenz.
  • Use storage: wenn aktiviert, speichert OpenAI Ihre Chats.
  • Extra body data: zusätzliche Parameter als JSON-Objekt, für Optionen, die ThunderAI nicht anzeigt.

Sie können diese Optionen auch für einen einzelnen Prompt festlegen, auf der Seite der benutzerdefinierten Prompts, sowie für jede KI-Funktion (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), mit der Schaltfläche Advanced options ihrer spezifischen Verbindung.

Tipps

  • Die API-Nutzung wird in Tokens gemessen. E-Mails sind meist kurz, daher sind die Kosten in der Regel sehr gering. Prüfen Sie Ihre Nutzung unter platform.openai.com/usage.
  • OpenAI fügt regelmäßig neue Modelle hinzu. Klicken Sie auf Update list, um die neuesten verfügbaren zu sehen.
  • Wird das Rate-Limit oder Kontingent von OpenAI überschritten, während ThunderAI mehrere E-Mails verarbeitet (Add Tags, Spam Filter, Summarize, Translate), stoppt die Verarbeitung von selbst und meldet, wie viele Nachrichten verarbeitet wurden.

Fehlerbehebung

Fehler "Authentication failed — check your API key" oder "Invalid API key"

Prüfen Sie, ob Sie den Schlüssel korrekt kopiert haben, ohne zusätzliche Leerzeichen. Funktioniert der Schlüssel weiterhin nicht, erzeugen Sie auf der OpenAI-Plattform einen neuen.

Fehler "You exceeded your current quota"

Ihr OpenAI-API-Konto hat kein Guthaben mehr. Laden Sie es auf unter platform.openai.com/settings/organization/billing.

In der Liste erscheinen keine Modelle

Wenn Sie "You have denied the optional permission needed to fetch models for this integration" sehen, klicken Sie erneut auf Update list und bestätigen Sie die Berechtigungsanfrage von Thunderbird. Andernfalls prüfen Sie, ob Ihr API-Schlüssel gültig ist, und kontrollieren Sie Ihre Internetverbindung.

Das Popup fragt nach einer Berechtigung, statt die Prompts anzuzeigen

Die Berechtigung für openai.com wurde noch nicht erteilt. Klicken Sie auf die Meldung im Popup: Die Willkommensseite von ThunderAI öffnet sich. Klicken Sie dort auf dieselbe Meldung und bestätigen Sie die Anfrage von Thunderbird. Sie können sie auch in Schritt 4 erteilen.
