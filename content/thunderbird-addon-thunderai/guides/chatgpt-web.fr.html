L'intégration ChatGPT Web Interface vous permet d'utiliser ThunderAI sans clé API.
ThunderAI interagit directement avec le site ChatGPT en votre nom, un compte ChatGPT gratuit suffit donc.

Clé API requise Option gratuite Idéal pour
Non Oui (même avec un compte ChatGPT gratuit) Démarrer rapidement, sans configuration de facturation

Prérequis

  • Un compte gratuit (ou payant) sur chatgpt.com
  • Thunderbird avec ThunderAI installé

Configuration

Le plus rapide est le Setup Wizard : ouvrez-le depuis la page d'accueil de ThunderAI, le popup de la barre d'outils ou la page des paramètres, et choisissez ChatGPT Web Interface. Continuez ensuite à partir de l'étape 3.
Pour une configuration manuelle, suivez toutes les étapes ci-dessous.

1. Ouvrir les paramètres de ThunderAI

Dans Thunderbird, accédez à Outils → Modules complémentaires et thèmes → ThunderAI → Préférences.

2. Sélectionner la ChatGPT Web Interface

Dans le panneau Connection Settings, choisissez ChatGPT Web Interface dans la liste déroulante Connection Type.

3. Accorder la permission requise

ThunderAI a besoin de la permission d'accéder à chatgpt.com. Ce n'est pas la page des paramètres qui la demande, mais le popup de ThunderAI.

  1. Cliquez sur le bouton ThunderAI dans la barre d'outils. Tant que la permission manque, le popup affiche, à la place de la liste des prompts, "To use the ChatGPT Web integration, you need to grant the required permission."
  2. Cliquez sur ce message : la page d'accueil de ThunderAI s'ouvre dans un nouvel onglet.
  3. Cliquez sur le même message en haut de la page d'accueil et acceptez la demande de permission de Thunderbird.
  4. Quand "Permission granted" apparaît, cliquez dessus pour fermer l'onglet.

Une fois la ChatGPT Web Interface sélectionnée, vous pouvez aussi ouvrir la page d'accueil depuis la carte Open the Welcome Page en haut de la page des paramètres : elle affiche la même demande.

Cette permission est optionnelle et utilisée uniquement pour interagir avec le site ChatGPT en votre nom. ThunderAI ne collecte ni ne stocke aucune de vos données.

4. Se connecter à ChatGPT

Vous ne devez le faire qu'une seule fois : Thunderbird maintient la session active.
La première fois que vous utilisez un prompt, ThunderAI ouvre la fenêtre de ChatGPT. Si vous n'êtes pas connecté, il vous le signale : connectez-vous avec votre compte dans cette fenêtre, fermez-la et relancez le prompt.
Si la connexion depuis cette fenêtre ne fonctionne pas, utilisez le bouton Open ChatGPT Tab dans les paramètres de ThunderAI : il ouvre chatgpt.com dans un onglet Thunderbird, où vous pouvez vous connecter. Fermez ensuite l'onglet et reprenez l'utilisation de ThunderAI.

5. Tester l'intégration

Ouvrez n'importe quel e-mail, cliquez sur le bouton ThunderAI dans la barre d'outils et sélectionnez un prompt (ex. : Summarize). ThunderAI ouvre une fenêtre ChatGPT, envoie le prompt et y affiche la réponse.

Options avancées

Cliquez sur Advanced options dans le panneau Connection Settings pour afficher ces paramètres :

  • ChatGPT Web Model : le modèle à utiliser. S'il est vide ou non valide, ChatGPT utilise son modèle par défaut. Ne fonctionne pas avec un compte ChatGPT gratuit.
  • ChatGPT Web Project et ChatGPT Web Custom GPT : un Projet ou un Custom GPT à toujours utiliser. Copiez la valeur depuis la barre d'adresse quand le Projet (/g/PROJECT-ID-PROJECT-NAME/project) ou le Custom GPT (/g/CUSTOM-GPT-ID) est ouvert dans ChatGPT. Vous pouvez aussi les définir pour un seul prompt, dans la page des prompts personnalisés.
  • ChatGPT Web temporary chat : utiliser une discussion temporaire.
  • Wait time for page load : combien de millisecondes ThunderAI attend le chargement de la page ChatGPT (1000 par défaut). Avec un Projet ou un Custom GPT, 1000 ms sont ajoutées.

Le bouton Open ChatGPT Tab applique lui aussi le modèle, le Projet et le Custom GPT configurés.

Conseils et limitations connues

  • La vitesse de réponse dépend du site ChatGPT et peut varier. L'intégration via API est généralement plus rapide et plus fiable.
  • Les comptes gratuits sont soumis aux limites d'utilisation de ChatGPT (rate limits, disponibilité des modèles).
  • Si ChatGPT modifie la mise en page de son site, l'intégration peut cesser de fonctionner temporairement jusqu'à la mise à jour de ThunderAI. Consultez la page de statut pour tout problème connu.
  • Les fonctions IA listées dans la page des paramètres (Add Tags, Spam Filter, Summarize, Translate, Calendar Event et Task) nécessitent une intégration API et ne fonctionnent pas avec la ChatGPT Web Interface. Vous pouvez garder ChatGPT Web comme connexion principale et attribuer à chacune de ces fonctions sa propre connexion API dans sa page de paramètres. Vos prompts du menu de la barre d'outils continuent de fonctionner avec ChatGPT Web.

Dépannage

Le popup demande une permission au lieu d'afficher les prompts

La permission pour chatgpt.com n'a pas encore été accordée. Voir l'étape 3.

ThunderAI indique que vous n'êtes pas connecté, ou n'affiche aucune réponse

Connectez-vous à ChatGPT dans la fenêtre ChatGPT ouverte par ThunderAI, fermez-la et réessayez. Si cela ne fonctionne pas, connectez-vous dans l'onglet ouvert par le bouton Open ChatGPT Tab dans les paramètres de ThunderAI.

"Could not locate the ChatGPT message box"

ThunderAI n'a pas trouvé la zone de texte de ChatGPT, généralement après une modification du site ChatGPT. Cliquez dans la zone de texte de ChatGPT dans la minute qui suit et ThunderAI continue. Si cela arrive à chaque fois, consultez la page de statut.

Les réponses sont lentes ou expirent

Il s'agit généralement d'un problème temporaire avec le site ChatGPT. Attendez un moment et réessayez, ou envisagez de passer à l'intégration OpenAI API pour des performances plus fiables.
