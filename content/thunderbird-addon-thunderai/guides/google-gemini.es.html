La integración con Google Gemini conecta ThunderAI con los modelos de IA Gemini de Google a través de la API de Gemini.
Incluye soporte para opciones avanzadas como System Instruction y Thinking Budget, útiles para usuarios avanzados que quieren mayor control sobre el comportamiento del modelo.

Clave de API requerida Opción gratuita Ideal para
Sí Sí (nivel gratuito generoso disponible) Usuarios del ecosistema de Google o que buscan una opción de API gratuita

Requisitos previos

  • Una cuenta de Google
  • Una clave de API de Gemini (nivel gratuito disponible)
  • Thunderbird con ThunderAI instalado

Cómo obtener una clave de API

  1. Ve a aistudio.google.com/apikey
  2. Haz clic en Create API key
  3. Selecciona un proyecto de Google Cloud existente o crea uno nuevo
  4. Copia la clave de API generada

La API de Gemini tiene un nivel gratuito con límites de frecuencia generosos, adecuado para uso personal con correos electrónicos. Hay niveles de pago disponibles si necesitas mayor rendimiento.

Configuración

Lo más rápido es el Setup Wizard: ábrelo desde la página de bienvenida de ThunderAI, el popup de la barra de herramientas o la página de ajustes, elige Google Gemini API, pega tu clave de API, elige un modelo y prueba la conexión. Después el asistente te permite activar las funciones de IA que quieras.
Para configurarla a mano, sigue los pasos de abajo.

1. Abre los ajustes de ThunderAI

En Thunderbird, ve a Herramientas → Complementos y temas → ThunderAI → Preferencias.

2. Selecciona la integración Google Gemini

En el panel Connection Settings, elige Google Gemini API en el desplegable Connection Type.

3. Introduce tu clave de API

Pega tu clave de API en el campo API Key. La clave se guarda localmente en Thunderbird y solo se envía a los servidores de Google.

4. Elige un modelo

Haz clic en Update list junto a Google Gemini API Models y después selecciona en la lista el modelo que quieres usar.

5. Prueba la conexión

Los ajustes se guardan en cuanto los cambias: no hay botón Guardar.
Haz clic en Test now en la barra bajo los ajustes de conexión. Si Thunderbird pide permiso para acceder a generativelanguage.googleapis.com, acéptalo. Si todo está bien, la barra muestra "Connected — Google Gemini API reachable". Después abre cualquier correo, haz clic en el botón de ThunderAI en la barra de herramientas y ejecuta un prompt.

Opciones avanzadas

Haz clic en Advanced options en el panel Connection Settings para mostrar los ajustes de abajo. Deja un campo vacío para que el modelo use su valor predeterminado.

  • System Instruction: un contexto fijo para todos tus prompts, por ejemplo para responder siempre de forma formal, en un idioma concreto o con un rol determinado.
  • Thinking Budget: cuántos tokens puede usar el modelo para razonar antes de responder. Introduce 0 para desactivar el razonamiento, o -1 para el razonamiento dinámico. Déjalo vacío si el modelo no admite razonamiento.
  • Temperature (0.0–2.0), Top P y Top K: cuán aleatoria o precisa es la respuesta. No todos los modelos admiten Top K.
  • Max output tokens: la longitud máxima de la respuesta. Vacío o 0 deja decidir al modelo.
  • Extra body data: parámetros adicionales para la API de Gemini, como objeto JSON, para opciones que ThunderAI no muestra, p. ej. {"generationConfig": {"seed": 42}}. Las claves dentro de generationConfig se combinan con las que genera ThunderAI.

También puedes definir estas opciones en un solo prompt, en la página de prompts personalizados, y en cada función de IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con el botón Advanced options de su conexión específica.

Consejos

  • El nivel gratuito tiene límites de solicitudes por minuto y por día, normalmente suficientes para un uso personal. Consulta los límites actuales en Google AI Studio.
  • Si se alcanza el límite mientras ThunderAI procesa varios correos (Add Tags, Spam Filter, Summarize, Translate), el procesamiento se detiene solo e indica cuántos mensajes se procesaron y, cuando Google lo indica, cuánto esperar.
  • La System Instruction es especialmente útil si quieres definir reglas generales para tu asistente de correo.

Solución de problemas

Error "Authentication failed — check your API key" o "API key not valid"

Verifica que la clave se copió correctamente. Si es necesario, genera una nueva desde AI Studio.

"Model not found" o lista de modelos vacía

Asegúrate de que tu clave de API tiene acceso a los modelos Gemini. Algunas claves creadas en proyectos de Google Cloud con restricciones pueden tener acceso limitado a los modelos.

Las solicitudes fallan después de cambiar las opciones avanzadas

Algunos modelos no aceptan todas las opciones (por ejemplo Top K, o un Thinking Budget en un modelo sin razonamiento). Vacía la opción y vuelve a intentarlo.
