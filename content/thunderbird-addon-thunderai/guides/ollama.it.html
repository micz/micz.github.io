L'integrazione con Ollama ti permette di eseguire modelli AI localmente sul tuo computer.
Con un'installazione locale le tue email non lasciano mai il tuo computer: nessuna chiave API, nessun servizio cloud, nessun costo oltre all'hardware.
Una chiave API serve solo se usi l'API ospitata da Ollama, o un server dietro un proxy che richiede l'autenticazione.

Chiave API richiesta Opzione gratuita Privato / Locale? Ideale per
No (opzionale) Sì (completamente gratuito, utilizzi il tuo hardware) Sì (tutto rimane sul tuo computer) Utenti attenti alla privacy, email sensibili, uso offline

Prerequisiti

  • Ollama installato e in esecuzione sul tuo computer (o accessibile sulla tua rete locale)
  • Almeno un modello scaricato in Ollama
  • Thunderbird con ThunderAI installato

Installazione di Ollama e download di un modello

Se non hai ancora installato Ollama:

  1. Scaricalo da ollama.com e segui le istruzioni di installazione per il tuo sistema operativo
  2. Apri un terminale e scarica un modello, ad esempio:
    ollama pull llama3
    Altre buone opzioni per le attività email: mistral, phi3, gemma2
  3. Verifica che Ollama sia in esecuzione:
    ollama list

Configurazione di CORS

Le estensioni di Thunderbird vengono eseguite in un ambiente isolato, quindi Ollama deve accettare le loro richieste. Ci sono due modi:

  • Imposta la variabile d'ambiente OLLAMA_ORIGINS su moz-extension://* e riavvia Ollama.
  • Oppure dai a ThunderAI il permesso di accedere al tuo server Ollama, con il pulsante Give permission to the current host nelle impostazioni di ThunderAI (sotto "Problems setting CORS?"), o accettando la richiesta che compare quando testi la connessione. Per un server su localhost o 127.0.0.1, Thunderbird chiede l'accesso a tutti i siti (<all_urls>).

Per configurazioni CORS più dettagliate, consulta la pagina informativa su Ollama e CORS.

Configurazione

Il modo più rapido è il Setup Wizard: aprilo dalla pagina di benvenuto di ThunderAI, dal popup della barra degli strumenti o dalla pagina delle impostazioni, scegli Ollama API (Local LLM), inserisci l'indirizzo del server, scegli un modello e testa la connessione. Poi il wizard ti permette di attivare le funzioni AI che ti servono.
Per configurarla a mano, segui i passi qui sotto.

1. Apri le impostazioni di ThunderAI

In Thunderbird, vai su Strumenti → Componenti aggiuntivi e temi → ThunderAI → Preferenze.

2. Seleziona l'integrazione Ollama

Nel pannello Connection Settings, scegli Ollama API (Local LLM) nel menu a tendina Connection Type.

3. Imposta l'indirizzo del server

Inserisci l'URL del tuo server Ollama nel campo Host Address. Il valore predefinito è:

http://localhost:11434

Se Ollama è in esecuzione su un altro computer della tua rete, sostituisci localhost con l'indirizzo IP di quel computer.

Lascia vuoto il campo Ollama API Key per una normale installazione locale. Serve solo per l'API ospitata su ollama.com, o per un server installato da te dietro un proxy che richiede l'autenticazione.

4. Scegli un modello

Clicca su Update list accanto a Ollama Models, poi seleziona dall'elenco il modello che vuoi usare.

5. Testa la connessione

Le impostazioni vengono salvate appena le modifichi: non c'è un pulsante Salva.
Clicca su Test now nella barra sotto le impostazioni di connessione e accetta la richiesta di permesso di Thunderbird, se compare (vedi Configurazione di CORS). Se è tutto a posto, la barra mostra "Connected — Ollama API (Local LLM) reachable". Poi apri una qualsiasi email, clicca sul pulsante ThunderAI nella barra degli strumenti e lancia un prompt.

Opzioni avanzate

Clicca su Advanced options nel pannello Connection Settings per mostrare le impostazioni qui sotto. Si adattano al modello selezionato.

  • System Prompt: inviato all'inizio di ogni conversazione, per dare al modello un ruolo o istruzioni fisse.
  • Enable thinking: fa ragionare il modello prima di rispondere. I livelli di ragionamento disponibili dipendono dal modello e compaiono dopo averlo selezionato. Model default non invia nulla e lascia decidere al modello, che in alcuni casi ragiona comunque: scegli Off per disattivare il ragionamento.
  • Temperature: valori più alti rendono le risposte più creative. Il valore predefinito è 0.8; sono consigliati valori tra 0 e 1.
  • Number of context tokens: quanto testo il modello può considerare. ThunderAI mostra il massimo supportato dal modello selezionato. Imposta 0 per usare il valore predefinito del server.
  • Keep model loaded: per quanto tempo Ollama tiene il modello in memoria dopo una richiesta, ad es. 5m o 30m, -1 per tenerlo sempre caricato, 0 per scaricarlo subito. Vuoto usa il valore predefinito del server (5 minuti). Aumentalo se Add Tags, il filtro antispam o il riassunto automatico lavorano sulla posta in arrivo: altrimenti il modello viene ricaricato per ogni messaggio.
  • Force JSON output: fa restituire a Ollama un JSON valido, con i modelli che supportano l'output strutturato.
  • Extra options: parametri aggiuntivi per Ollama, in formato JSON, ad es. {"top_p": 0.9, "seed": 42} o {"num_predict": 512}.

Puoi impostare queste opzioni anche sul singolo prompt, nella pagina dei prompt personalizzati, e su ciascuna funzione AI (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con il pulsante Advanced options della sua connessione specifica.

Suggerimenti

  • Le prestazioni dipendono dal tuo hardware. Un computer moderno con almeno 16 GB di RAM gestisce senza problemi modelli come llama3 o mistral. Una GPU velocizza molto l'elaborazione.
  • I modelli più piccoli (7B parametri) sono più veloci ma meno capaci; quelli più grandi (13B, 70B) danno risultati migliori ma richiedono più risorse.
  • Per le email, mistral e llama3 sono scelte diffuse, con un buon equilibrio tra qualità e velocità.
  • Se le funzioni automatiche (Add Tags, Spam Filter, Summarize, Translate) si fermano per timeout con un modello lento, aumenta Special command timeout (ms) nelle impostazioni di ThunderAI.

Risoluzione dei problemi

"Failed to connect" o nessuna risposta

Verifica che Ollama sia effettivamente in esecuzione (ollama list in un terminale). Controlla che l'Host Address nelle impostazioni di ThunderAI corrisponda alla tua installazione di Ollama.

Errore CORS

La variabile OLLAMA_ORIGINS non è impostata, oppure Ollama non è stato riavviato dopo averla impostata. Ripeti i passi di Configurazione di CORS, oppure usa al suo posto il pulsante Give permission to the current host.

Elenco dei modelli vuoto

Assicurati di aver scaricato almeno un modello con ollama pull <nomemodello> e che Ollama sia in esecuzione.

Il modello ragiona anche quando non vuoi

Alcuni modelli ragionano per impostazione predefinita. Imposta Enable thinking su Off nelle opzioni avanzate.
