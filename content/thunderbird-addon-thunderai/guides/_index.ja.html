ThunderAI を最大限に活用するためのステップバイステップのガイドです。
使い始めたばかりの方も、特定の AI 連携を設定したい方も、必要な情報はすべてここにあります。
最初のカスタムプロンプトの作り方は、チュートリアルをご覧ください。
プロバイダーに接続する最も簡単な方法は Setup Wizard です。ThunderAI のウェルカムページ、ツールバーのポップアップ、または設定ページから開けます。

AI 連携

ThunderAI を、お好みの AI バックエンドに接続します。どれを選べばよいか迷ったら、下の比較表をご覧ください。

  • ChatGPT Web Interface — API キーは不要で、無料の ChatGPT アカウントでも使えます。
  • OpenAI API — API キーを使って ChatGPT のモデルに直接接続します。
  • Google Gemini — Google の Gemini モデルに接続します。無料枠があります。
  • Claude API — Anthropic の Claude モデルです。メールの詳しい分析に適しています。
  • Ollama（ローカル AI） — AI を完全にお使いのコンピューター上で実行します。プライベート、無料で、インターネット接続も不要です。
  • OpenAI Compatible API — LM Studio、DeepSeek、Mistral、OpenRouter など。
