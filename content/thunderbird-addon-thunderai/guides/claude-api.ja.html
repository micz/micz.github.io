Claude API との連携により、ThunderAI を Anthropic の Claude AI モデルに接続できます。
Claude は、丁寧でよく構成された回答を生成し、長い文書の扱いにも優れていることで知られています。詳しいメールを読んだり書いたりするのに最適です。

必要 なし（従量課金） 詳しい分析、長いメール、構成のしっかりした文章

前提条件

  • API アクセスが可能な Anthropic アカウント
  • 有効な Claude API キー
  • ThunderAI をインストールした Thunderbird

API キーの取得

  1. console.anthropic.com/settings/keys にアクセスします
  2. Create Key をクリックします
  3. 名前を付けて、すぐにキーをコピーします。キーは二度と表示されません

セットアップ

最も簡単な方法は Setup Wizard です。ThunderAI のウェルカムページ、ツールバーのポップアップ、または設定ページから開き、 Claude API を選択して API キーを貼り付け、モデルを選んで接続をテストします。 その後、ウィザードで使いたい AI 機能を有効にできます。
手動で設定する場合は、以下の手順に従ってください。

1. ThunderAI の設定を開く

Thunderbird で ツール → アドオンとテーマ → ThunderAI → 設定 を開きます。

2. Claude API 連携を選択する

Connection Settings パネルで、Connection Type のドロップダウンから Claude API を選択します。

3. API キーを入力する

Claude API Key 欄に API キーを貼り付けます。キーは Thunderbird 内にローカルで保存され、Anthropic のサーバー以外に送信されることはありません。

4. モデルを選択する

Claude Models の横にある Update list をクリックします。初回は、Thunderbird が anthropic.com へのアクセス権限を求めます。承認しないと、ThunderAI は Claude API に接続できません。その後、一覧から使用するモデルを選択します。

この権限は任意であり、Anthropic の API サーバーとの通信にのみ使用されます。ThunderAI がデータを収集することはありません。

5. 接続をテストする

設定は変更するとすぐに保存されます。保存ボタンはありません。
接続設定の下にあるバーの Test now をクリックします。問題がなければ "Connected — Claude API reachable" と表示されます。その後、任意のメールを開き、ツールバーの ThunderAI ボタンをクリックしてプロンプトを実行します。

詳細オプション

Connection Settings パネルの Advanced options をクリックすると、以下の設定が表示されます。 これらは選択したモデルに合わせて変わります。モデルが受け付けない設定は無効になり、その理由を説明する注記が表示され、送信されません。 別のモデルに戻した場合に備えて、保存した値は保持されます。

  • System Prompt: すべてのプロンプトと一緒にモデルへ送信される指示とコンテキストです。
  • Max Tokens: 回答の最大の長さです。
  • Effort: モデルがリクエストにどれだけ推論を費やすかです。レベルが高いほど複雑なタスクでよりよい回答が得られますが、消費するトークンが増え、時間もかかります。 API に任せる場合は Default のままにしてください。古い Claude モデルはこの設定に対応していません。
  • Extended thinking budget (tokens): 古いモデル向けの設定で、モデルが思考に使えるトークンの最大数です。0 にすると拡張思考がオフになります。 1024 以上、かつ Max Tokens 未満である必要があります。そうでない場合、設定画面に警告が表示され、値は送信されません。
  • Temperature（0.0～1.0）、Top P、Top K: 回答のランダムさ、または的確さを調整します。 新しい Claude モデルはこれらを受け付けないため、代わりに Effort を使用してください。
  • Stop sequences: モデルの書き込みを停止させるテキストで、1 行に 1 つずつ指定します。すべての Claude モデルで使用できます。
  • Claude API Version: Anthropic API のバージョンです。よくわからない場合は変更しないでください。

これらのオプションは、カスタムプロンプトのページで個々のプロンプトに設定することもできます。また、各 AI 機能（Add Tags、Spam Filter、 Summarize、Translate、Calendar Event、Task）にも、それぞれの専用接続の Advanced options ボタンから設定できます。

ヒント

  • Claude モデルは広いコンテキストウィンドウにより大量のテキストをうまく扱えるため、長いメールスレッドの処理に役立ちます。
  • Claude は詳しく回答する傾向があります。短い出力を好む場合は、プロンプト、カスタムプロンプト、または System Prompt に「簡潔に」などの指示を直接追加してください。
  • 新しい Claude モデルは、一覧に表示された時点ですぐに使えます。モデルがいずれかのオプションを拒否した場合、ThunderAI はそのオプションを外して自動的に一度だけリクエストを再送します。
  • ThunderAI が複数のメールを処理している間（Add Tags、Spam Filter、Summarize、Translate）に Anthropic のレート制限を超えた場合、処理は自動的に停止し、処理済みのメッセージ数が表示されます。
  • API の使用量とコストは console.anthropic.com で確認できます。

トラブルシューティング

"Authentication failed — check your API key" または "Invalid API key" エラー

キーが正しくコピーされているか確認してください。必要に応じて、Anthropic コンソールで新しいキーを生成してください。

ポップアップにプロンプトではなく権限のリクエストが表示される

anthropic.com の権限がまだ許可されていません。この権限がないと、ThunderAI は Claude API に接続できません。 ポップアップのメッセージをクリックすると、ThunderAI のウェルカムページが開きます。そこで同じメッセージをクリックし、Thunderbird のリクエストを承認してください。 手順 4 から許可することもできます。

"Credit balance too low" エラー

console.anthropic.com/settings/billing で Anthropic アカウントにクレジットを追加してください。

一覧にモデルが表示されない

"You have denied the optional permission needed to fetch models for this integration" と表示される場合は、 もう一度 Update list をクリックし、Thunderbird の権限リクエストを承認してください。それ以外の場合は、API キーが有効であることを確認してください。
