Die Integration mit der ChatGPT Web Interface ermöglicht es Ihnen, ThunderAI ohne API-Schlüssel zu nutzen.
ThunderAI interagiert direkt mit der ChatGPT-Website in Ihrem Namen, sodass ein kostenloses ChatGPT-Konto ausreicht.

API-Schlüssel erforderlich Kostenlose Option Geeignet für
Nein Ja (auch mit einem kostenlosen ChatGPT-Konto) Schneller Einstieg, keine Abrechnungseinrichtung

Voraussetzungen

  • Ein kostenloses (oder kostenpflichtiges) Konto auf chatgpt.com
  • Thunderbird mit installiertem ThunderAI

Einrichtung

Am schnellsten geht es mit dem Setup Wizard: Öffnen Sie ihn über die Willkommensseite von ThunderAI, das Popup in der Symbolleiste oder die Einstellungsseite, und wählen Sie ChatGPT Web Interface. Fahren Sie dann mit Schritt 3 fort.
Für die manuelle Einrichtung folgen Sie allen Schritten unten.

1. ThunderAI-Einstellungen öffnen

Gehen Sie in Thunderbird zu Extras → Add-ons und Themes → ThunderAI → Einstellungen.

2. ChatGPT Web Interface auswählen

Wählen Sie im Bereich Connection Settings im Dropdown Connection Type die Option ChatGPT Web Interface.

3. Erforderliche Berechtigung erteilen

ThunderAI benötigt die Berechtigung, auf chatgpt.com zuzugreifen. Nicht die Einstellungsseite fragt danach, sondern das ThunderAI-Popup.

  1. Klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste. Solange die Berechtigung fehlt, zeigt das Popup statt der Prompt-Liste "To use the ChatGPT Web integration, you need to grant the required permission."
  2. Klicken Sie auf diese Meldung: Die Willkommensseite von ThunderAI öffnet sich in einem neuen Tab.
  3. Klicken Sie oben auf der Willkommensseite auf dieselbe Meldung und bestätigen Sie die Berechtigungsanfrage von Thunderbird.
  4. Wenn "Permission granted" erscheint, klicken Sie darauf, um den Tab zu schließen.

Sobald ChatGPT Web Interface ausgewählt ist, können Sie die Willkommensseite auch über die Karte Open the Welcome Page oben auf der Einstellungsseite öffnen: Sie zeigt dieselbe Anfrage.

Diese Berechtigung ist optional und wird ausschließlich dazu verwendet, in Ihrem Namen mit der ChatGPT-Website zu interagieren. ThunderAI erfasst oder speichert keine Ihrer Daten.

4. Bei ChatGPT anmelden

Dies müssen Sie nur einmal tun: Thunderbird hält die Sitzung aktiv.
Wenn Sie zum ersten Mal einen Prompt verwenden, öffnet ThunderAI das ChatGPT-Fenster. Sind Sie nicht angemeldet, weist ThunderAI darauf hin: Melden Sie sich in diesem Fenster mit Ihrem Konto an, schließen Sie es und führen Sie den Prompt erneut aus.
Funktioniert die Anmeldung in diesem Fenster nicht, verwenden Sie die Schaltfläche Open ChatGPT Tab in den ThunderAI-Einstellungen: Sie öffnet chatgpt.com in einem Thunderbird-Tab, in dem Sie sich anmelden können. Schließen Sie danach den Tab und verwenden Sie ThunderAI wie gewohnt.

5. Integration testen

Öffnen Sie eine beliebige E-Mail, klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste und wählen Sie einen Prompt (z. B. Summarize). ThunderAI öffnet ein ChatGPT-Fenster, sendet den Prompt und zeigt dort die Antwort.

Erweiterte Optionen

Klicken Sie im Bereich Connection Settings auf Advanced options, um diese Einstellungen anzuzeigen:

  • ChatGPT Web Model: das zu verwendende Modell. Ist es leer oder ungültig, verwendet ChatGPT sein Standardmodell. Funktioniert nicht mit einem kostenlosen ChatGPT-Konto.
  • ChatGPT Web Project und ChatGPT Web Custom GPT: ein Projekt oder Custom GPT, das immer verwendet wird. Kopieren Sie den Wert aus der Adressleiste, wenn das Projekt (/g/PROJECT-ID-PROJECT-NAME/project) oder das Custom GPT (/g/CUSTOM-GPT-ID) in ChatGPT geöffnet ist. Sie können sie auch für einen einzelnen Prompt festlegen, auf der Seite der benutzerdefinierten Prompts.
  • ChatGPT Web temporary chat: einen temporären Chat verwenden.
  • Wait time for page load: wie viele Millisekunden ThunderAI auf das Laden der ChatGPT-Seite wartet (Standard 1000). Mit einem Projekt oder Custom GPT kommen 1000 ms hinzu.

Auch die Schaltfläche Open ChatGPT Tab übernimmt das eingestellte Modell, Projekt und Custom GPT.

Tipps und bekannte Einschränkungen

  • Die Antwortgeschwindigkeit hängt von der ChatGPT-Website ab und kann variieren. Die API-Integration ist in der Regel schneller und zuverlässiger.
  • Kostenlose Konten unterliegen den eigenen Nutzungslimits von ChatGPT (Rate-Limits, Modellverfügbarkeit).
  • Wenn ChatGPT das Layout seiner Website ändert, kann die Integration vorübergehend aufhören zu funktionieren, bis ThunderAI aktualisiert wird. Prüfen Sie die Statusseite auf bekannte Probleme.
  • Die KI-Funktionen auf der Einstellungsseite (Add Tags, Spam Filter, Summarize, Translate, Calendar Event und Task) benötigen eine API-Integration und funktionieren nicht mit der ChatGPT Web Interface. Sie können ChatGPT Web als Hauptverbindung behalten und jeder dieser Funktionen auf ihrer Einstellungsseite eine eigene API-Verbindung zuweisen. Ihre Prompts aus dem Symbolleistenmenü funktionieren weiterhin mit ChatGPT Web.

Fehlerbehebung

Das Popup fragt nach einer Berechtigung, statt die Prompts anzuzeigen

Die Berechtigung für chatgpt.com wurde noch nicht erteilt. Siehe Schritt 3.

ThunderAI meldet, dass Sie nicht angemeldet sind, oder zeigt keine Antwort

Melden Sie sich im von ThunderAI geöffneten ChatGPT-Fenster bei ChatGPT an, schließen Sie es und versuchen Sie es erneut. Wenn das nicht funktioniert, melden Sie sich in dem Tab an, den die Schaltfläche Open ChatGPT Tab in den ThunderAI-Einstellungen öffnet.

"Could not locate the ChatGPT message box"

ThunderAI hat das Textfeld von ChatGPT nicht gefunden, meist nach einer Änderung an der ChatGPT-Website. Klicken Sie innerhalb einer Minute in das Textfeld von ChatGPT, dann fährt ThunderAI fort. Wenn das jedes Mal passiert, prüfen Sie die Statusseite.

Antworten sind langsam oder laufen ab

Dies ist in der Regel ein vorübergehendes Problem mit der ChatGPT-Website. Warten Sie einen Moment und versuchen Sie es erneut, oder wechseln Sie zur Integration OpenAI API für zuverlässigere Leistung.
