Die Integration mit Google Gemini verbindet ThunderAI über die Gemini API mit Googles Gemini-KI-Modellen.
Sie unterstützt erweiterte Optionen wie System Instruction und Thinking Budget, die für Nutzer nützlich sind, die das Verhalten des Modells genauer steuern möchten.

API-Schlüssel erforderlich Kostenlose Option Geeignet für
Ja Ja (großzügiges kostenloses Kontingent verfügbar) Nutzer des Google-Ökosystems oder wer eine kostenlose API-Option sucht

Voraussetzungen

  • Ein Google-Konto
  • Ein Gemini API-Schlüssel (kostenloses Kontingent verfügbar)
  • Thunderbird mit installiertem ThunderAI

API-Schlüssel erhalten

  1. Gehen Sie zu aistudio.google.com/apikey
  2. Klicken Sie auf Create API key
  3. Wählen Sie ein bestehendes Google Cloud-Projekt aus oder erstellen Sie ein neues
  4. Kopieren Sie den generierten API-Schlüssel

Die Gemini API bietet ein kostenloses Kontingent mit großzügigen Rate-Limits, das für den persönlichen E-Mail-Einsatz geeignet ist. Kostenpflichtige Stufen sind verfügbar, wenn Sie einen höheren Durchsatz benötigen.

Einrichtung

Am schnellsten geht es mit dem Setup Wizard: Öffnen Sie ihn über die Willkommensseite von ThunderAI, das Popup in der Symbolleiste oder die Einstellungsseite, wählen Sie Google Gemini API, fügen Sie Ihren API-Schlüssel ein, wählen Sie ein Modell und testen Sie die Verbindung. Anschließend können Sie im Wizard die gewünschten KI-Funktionen aktivieren.
Für die manuelle Einrichtung folgen Sie den Schritten unten.

1. ThunderAI-Einstellungen öffnen

Gehen Sie in Thunderbird zu Extras → Add-ons und Themes → ThunderAI → Einstellungen.

2. Google-Gemini-Integration auswählen

Wählen Sie im Bereich Connection Settings im Dropdown Connection Type die Option Google Gemini API.

3. API-Schlüssel eingeben

Fügen Sie Ihren API-Schlüssel in das Feld API Key ein. Der Schlüssel wird lokal in Thunderbird gespeichert und nur an die Server von Google gesendet.

4. Modell auswählen

Klicken Sie neben Google Gemini API Models auf Update list und wählen Sie dann das gewünschte Modell aus der Liste.

5. Verbindung testen

Einstellungen werden gespeichert, sobald Sie sie ändern: Es gibt keine Speichern-Schaltfläche.
Klicken Sie in der Leiste unter den Verbindungseinstellungen auf Test now. Wenn Thunderbird nach der Berechtigung fragt, auf generativelanguage.googleapis.com zuzugreifen, bestätigen Sie sie. Wenn alles in Ordnung ist, zeigt die Leiste "Connected — Google Gemini API reachable". Öffnen Sie dann eine beliebige E-Mail, klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste und führen Sie einen Prompt aus.

Erweiterte Optionen

Klicken Sie im Bereich Connection Settings auf Advanced options, um die folgenden Einstellungen anzuzeigen. Lassen Sie ein Feld leer, damit das Modell seinen Standardwert verwendet.

  • System Instruction: ein fester Kontext für alle Ihre Prompts, zum Beispiel immer förmlich, in einer bestimmten Sprache oder in einer bestimmten Rolle zu antworten.
  • Thinking Budget: wie viele Tokens das Modell zum Nachdenken vor der Antwort verwenden darf. Geben Sie 0 ein, um das Nachdenken auszuschalten, oder -1 für dynamisches Nachdenken. Lassen Sie das Feld leer, wenn das Modell kein Nachdenken unterstützt.
  • Temperature (0.0–2.0), Top P und Top K: wie zufällig oder fokussiert die Antwort ist. Nicht jedes Modell unterstützt Top K.
  • Max output tokens: die maximale Länge der Antwort. Leer oder 0 überlässt die Entscheidung dem Modell.
  • Extra body data: zusätzliche Parameter für die Gemini API als JSON-Objekt, für Optionen, die ThunderAI nicht anzeigt, z. B. {"generationConfig": {"seed": 42}}. Die Schlüssel in generationConfig werden mit denen zusammengeführt, die ThunderAI erzeugt.

Sie können diese Optionen auch für einen einzelnen Prompt festlegen, auf der Seite der benutzerdefinierten Prompts, sowie für jede KI-Funktion (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), mit der Schaltfläche Advanced options ihrer spezifischen Verbindung.

Tipps

  • Das kostenlose Kontingent hat Anfragelimits pro Minute und pro Tag, die für die private Nutzung in der Regel ausreichen. Die aktuellen Limits finden Sie in Google AI Studio.
  • Wird das Limit erreicht, während ThunderAI mehrere E-Mails verarbeitet (Add Tags, Spam Filter, Summarize, Translate), stoppt die Verarbeitung von selbst und meldet, wie viele Nachrichten verarbeitet wurden und, wenn Google es angibt, wie lange zu warten ist.
  • Die System Instruction ist besonders nützlich, wenn Sie allgemeine Regeln für Ihren E-Mail-Assistenten festlegen möchten.

Fehlerbehebung

Fehler "Authentication failed — check your API key" oder "API key not valid"

Prüfen Sie, ob der Schlüssel korrekt kopiert wurde. Erzeugen Sie bei Bedarf in AI Studio einen neuen.

"Model not found" oder leere Modellliste

Stellen Sie sicher, dass Ihr API-Schlüssel Zugriff auf die Gemini-Modelle hat. Schlüssel aus eingeschränkten Google-Cloud-Projekten können nur begrenzten Zugriff auf Modelle haben.

Anfragen schlagen fehl, nachdem die erweiterten Optionen geändert wurden

Manche Modelle akzeptieren nicht jede Option (zum Beispiel Top K oder ein Thinking Budget bei einem Modell ohne Nachdenken). Leeren Sie die Option und versuchen Sie es erneut.
