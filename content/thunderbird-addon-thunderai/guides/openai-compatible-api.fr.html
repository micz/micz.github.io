L'intégration OpenAI Compatible API vous permet de connecter ThunderAI à n'importe quel serveur suivant le format API d'OpenAI.
Cela inclut les serveurs locaux comme LM Studio, les services hébergés comme DeepSeek, Grok, Mistral AI, OpenRouter et Perplexity, ainsi que tout endpoint personnalisé ou auto-hébergé.

Configurations prédéfinies

ThunderAI inclut des préréglages prêts à l'emploi pour les services OpenAI-compatibles les plus populaires. Si vous utilisez l'un d'eux, sélectionnez le préréglage et fournissez uniquement votre clé API :

Préréglage Notes
DeepSeek API Rapide et économique, modèles de raisonnement avancés
Grok API Modèles Grok de xAI
Mistral API Modèles hébergés par Mistral AI
OpenRouter API Accédez à de nombreux fournisseurs via une seule clé API
Perplexity API Inclut des modèles avec recherche web intégrée

Configuration

Le plus rapide est le Setup Wizard : ouvrez-le depuis la page d'accueil de ThunderAI, le popup de la barre d'outils ou la page des paramètres, choisissez OpenAI Compatible API, sélectionnez un service ou saisissez l'adresse de votre serveur, choisissez un modèle et testez la connexion. L'assistant vous permet ensuite d'activer les fonctions IA souhaitées.
Pour une configuration manuelle, suivez les étapes ci-dessous.

1. Ouvrir les paramètres de ThunderAI

Dans Thunderbird, accédez à Outils → Modules complémentaires et thèmes → ThunderAI → Préférences.

2. Sélectionner l'intégration OpenAI Compatible API

Dans le panneau Connection Settings, choisissez OpenAI Compatible API dans la liste déroulante Connection Type.

3a. Utiliser un préréglage

Si votre fournisseur a un préréglage, sélectionnez-le dans Available Services et confirmez. ThunderAI remplit l'adresse du serveur, le paramètre "v1" et le nom de la discussion, et vide la liste des modèles. Saisissez votre clé API et continuez à partir de l'étape 5.

3b. Configuration manuelle

Si votre fournisseur n'est pas dans la liste, choisissez Custom et configurez-le manuellement :

  • Host Address : l'URL de base de votre serveur, sans /v1. Pour LM Studio en local, c'est généralement http://localhost:1234. L'adresse d'un serveur distant fonctionne aussi.
  • Keep the "v1" compatibility (dans les options avancées, cochée par défaut) : ThunderAI ajoute /v1 à l'adresse, comme dans http://localhost:1234/v1/chat/completions. Décochez-la si les points d'accès de votre fournisseur n'ont pas de segment /v1.

4. Saisir votre clé API (si nécessaire)

Saisissez-la dans le champ OpenAI Comp API Key, qui est facultatif. Les serveurs locaux comme LM Studio ne demandent généralement pas de clé API, vous pouvez donc le laisser vide. Les services hébergés exigent une clé valide.

5. Choisir un modèle

Cliquez sur Update list à côté de OpenAI Compatible API Models, puis sélectionnez votre modèle dans la liste.

Si le serveur ne fournit pas de liste de modèles, cliquez sur Add manually et saisissez le nom du modèle indiqué par votre fournisseur. Clear list vide la liste.

6. Tester la connexion

Les paramètres sont enregistrés dès que vous les modifiez : il n'y a pas de bouton Enregistrer.
Cliquez sur Test now dans la barre sous les paramètres de connexion et acceptez la demande de permission de Thunderbird, si elle apparaît. Si tout va bien, la barre affiche "Connected — OpenAI Compatible API reachable". Ouvrez ensuite n'importe quel e-mail, cliquez sur le bouton ThunderAI dans la barre d'outils et lancez un prompt.

Options avancées

Cliquez sur Advanced options dans le panneau Connection Settings pour afficher ces paramètres :

  • Keep the "v1" compatibility : voir l'étape 3b.
  • Chat Name : le nom affiché pour l'IA dans la fenêtre de discussion de ThunderAI.
  • Temperature : entre 0 et 2. Des valeurs plus élevées rendent la sortie plus aléatoire, des valeurs plus basses plus ciblée.
  • Extra body data : paramètres supplémentaires sous forme d'objet JSON, pour les options que le service prend en charge mais que ThunderAI n'affiche pas, par ex. {"top_p": 0.9}, ou {"chat_template_kwargs": {"thinking": false}} pour désactiver le mode de réflexion sur les serveurs qui le prennent en charge.

Vous pouvez aussi définir ces options pour un seul prompt, dans la page des prompts personnalisés, et pour chaque fonction IA (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), avec le bouton Advanced options de sa connexion spécifique.

LM Studio — configuration rapide

LM Studio fournit un serveur local avec une API compatible OpenAI et une interface graphique pour télécharger et gérer les modèles.

  1. Téléchargez et installez LM Studio depuis lmstudio.ai
  2. Téléchargez un modèle de votre choix depuis le catalogue de modèles de LM Studio
  3. Dans LM Studio, démarrez le serveur local
  4. Dans ThunderAI, choisissez Custom, réglez la Host Address sur http://localhost:1234, laissez la compatibilité "v1" cochée, laissez la clé API vide et sélectionnez votre modèle

Conseils

  • OpenRouter est une excellente option si vous voulez accéder à de nombreux modèles différents (dont Claude, Gemini et Mistral) avec une seule clé API et un seul compte de facturation.
  • Avec les serveurs locaux, les performances dépendent de votre matériel — consultez le guide Ollama pour des conseils matériels.
  • Si les requêtes échouent avec une erreur CORS et que vous ne pouvez pas modifier la configuration du serveur, cliquez sur Give permission to the current host dans les paramètres de ThunderAI (sous "Problems setting CORS?"). Pour un serveur sur localhost ou 127.0.0.1, Thunderbird demande l'accès à tous les sites (<all_urls>).
  • Si la limite de requêtes ou le quota du service est dépassé pendant que ThunderAI traite plusieurs e-mails (Add Tags, Spam Filter, Summarize, Translate), le traitement s'arrête de lui-même et indique combien de messages ont été traités.

Dépannage

"Connection refused" sur un serveur local

Assurez-vous que le serveur local (par ex. LM Studio) est bien en cours d'exécution et que la Host Address dans ThunderAI correspond au port sur lequel il écoute.

Erreur "401 Unauthorized"

Vérifiez votre clé API. Pour les serveurs locaux qui ne demandent pas de clé, essayez une valeur fictive comme none. Certains serveurs refusent un champ de clé vide.

Liste de modèles vide

Cliquez sur Add manually et saisissez le nom du modèle indiqué dans la documentation de votre fournisseur ou de votre serveur.

"404 Not Found", ou erreurs dues au "v1" dans l'URL

Vérifiez que la Host Address ne se termine pas par /v1, car ThunderAI l'ajoute quand Keep the "v1" compatibility est cochée. Si les points d'accès de votre fournisseur n'ont pas de /v1, décochez cette option.
