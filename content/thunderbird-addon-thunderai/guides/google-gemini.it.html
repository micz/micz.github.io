L'integrazione con Google Gemini connette ThunderAI ai modelli AI Gemini di Google tramite la Gemini API.
Include il supporto per opzioni avanzate come System Instruction e Thinking Budget, utili per gli utenti che desiderano maggiore controllo sul comportamento del modello.

Prerequisiti

  • Un account Google
  • Una chiave Gemini API (livello gratuito disponibile)
  • Thunderbird con ThunderAI installato

Ottenere una chiave API

  1. Vai su aistudio.google.com/apikey
  2. Clicca su Create API key
  3. Seleziona un progetto Google Cloud esistente o creane uno nuovo
  4. Copia la chiave API generata

La Gemini API offre un livello gratuito con limiti generosi, adatto all'uso personale delle email. Sono disponibili piani a pagamento se hai bisogno di maggiore throughput.

Configurazione

Il modo più rapido è il Setup Wizard: aprilo dalla pagina di benvenuto di ThunderAI, dal popup della barra degli strumenti o dalla pagina delle impostazioni, scegli Google Gemini API, incolla la chiave API, scegli un modello e testa la connessione. Poi il wizard ti permette di attivare le funzioni AI che ti servono.
Per configurarla a mano, segui i passi qui sotto.

1. Apri le impostazioni di ThunderAI

In Thunderbird, vai su Strumenti → Componenti aggiuntivi e temi → ThunderAI → Preferenze.

2. Seleziona l'integrazione Google Gemini

Nel pannello Connection Settings, scegli Google Gemini API nel menu a tendina Connection Type.

3. Inserisci la chiave API

Incolla la chiave API nel campo API Key. La chiave è memorizzata localmente in Thunderbird e viene inviata solo ai server di Google.

4. Scegli un modello

Clicca su Update list accanto a Google Gemini API Models, poi seleziona dall'elenco il modello che vuoi usare.

5. Testa la connessione

Le impostazioni vengono salvate appena le modifichi: non c'è un pulsante Salva.
Clicca su Test now nella barra sotto le impostazioni di connessione. Se Thunderbird chiede il permesso di accedere a generativelanguage.googleapis.com, accettalo. Se è tutto a posto, la barra mostra "Connected — Google Gemini API reachable". Poi apri una qualsiasi email, clicca sul pulsante ThunderAI nella barra degli strumenti e lancia un prompt.

Opzioni avanzate

Clicca su Advanced options nel pannello Connection Settings per mostrare le impostazioni qui sotto. Lascia un campo vuoto per far usare al modello il suo valore predefinito.

  • System Instruction: un contesto fisso per tutti i tuoi prompt, ad esempio per rispondere sempre in modo formale, in una certa lingua o con un certo ruolo.
  • Thinking Budget: quanti token il modello può usare per ragionare prima di rispondere. Inserisci 0 per disattivare il ragionamento, o -1 per il ragionamento dinamico. Lascialo vuoto se il modello non supporta il ragionamento.
  • Temperature (0.0–2.0), Top P e Top K: quanto la risposta è casuale o mirata. Non tutti i modelli supportano Top K.
  • Max output tokens: la lunghezza massima della risposta. Vuoto o 0 lascia decidere al modello.
  • Extra body data: parametri aggiuntivi per la Gemini API, in formato JSON, per le opzioni che ThunderAI non mostra, ad es. {"generationConfig": {"seed": 42}}. Le chiavi dentro generationConfig vengono unite a quelle generate da ThunderAI.

Puoi impostare queste opzioni anche sul singolo prompt, nella pagina dei prompt personalizzati, e su ciascuna funzione AI (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), con il pulsante Advanced options della sua connessione specifica.

Suggerimenti

  • Il livello gratuito ha limiti di richieste al minuto e al giorno, in genere sufficienti per un uso personale. Controlla i limiti attuali in Google AI Studio.
  • Se il limite viene raggiunto mentre ThunderAI elabora più email (Add Tags, Spam Filter, Summarize, Translate), l'elaborazione si ferma da sola e ti dice quanti messaggi sono stati elaborati e, quando Google lo indica, quanto aspettare.
  • La System Instruction è particolarmente utile se vuoi definire regole generali per il tuo assistente email.

Risoluzione dei problemi

Errore "Authentication failed — check your API key" o "API key not valid"

Verifica di aver copiato correttamente la chiave. Se necessario, generane una nuova da AI Studio.

"Model not found" o elenco dei modelli vuoto

Assicurati che la tua chiave API abbia accesso ai modelli Gemini. Alcune chiavi create in progetti Google Cloud con restrizioni possono avere un accesso limitato ai modelli.

Le richieste falliscono dopo aver cambiato le opzioni avanzate

Alcuni modelli non accettano tutte le opzioni (ad esempio Top K, o un Thinking Budget su un modello senza ragionamento). Svuota l'opzione e riprova.
