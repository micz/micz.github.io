The ChatGPT Web Interface integration lets you use ThunderAI without an API key.
ThunderAI interacts directly with the ChatGPT website on your behalf, so a free ChatGPT account is all you need.

API key required Free option Best for
No Yes (also with a free ChatGPT account) Getting started quickly, no billing setup

Prerequisites

  • A free (or paid) account on chatgpt.com
  • Thunderbird with ThunderAI installed

Setup

The quickest way is the Setup Wizard: open it from the ThunderAI welcome page, the toolbar popup or the settings page, and choose ChatGPT Web Interface. Then continue from step 3.
To set it up by hand, follow all the steps below.

1. Open the ThunderAI settings

In Thunderbird, go to Tools → Add-ons and Themes → ThunderAI → Preferences.

2. Select the ChatGPT Web Interface

In the Connection Settings panel, choose ChatGPT Web Interface in the Connection Type dropdown.

3. Grant the required permission

ThunderAI needs permission to access chatgpt.com. The settings page does not ask for it: the ThunderAI popup does.

  1. Click the ThunderAI toolbar button. While the permission is missing, the popup shows "To use the ChatGPT Web integration, you need to grant the required permission." instead of the prompts list.
  2. Click that message: the ThunderAI welcome page opens in a new tab.
  3. Click the same message at the top of the welcome page and accept Thunderbird's permission request.
  4. When "Permission granted" appears, click it to close the tab.

Once ChatGPT Web Interface is selected, you can also open the welcome page from the Open the Welcome Page card at the top of the settings page: it shows the same request.

This permission is optional and only used to interact with the ChatGPT website on your behalf. ThunderAI does not collect or store any of your data.

4. Log in to ChatGPT

You only need to do this once: Thunderbird keeps the session active.
The first time you use a prompt, ThunderAI opens the ChatGPT window. If you are not logged in, it tells you so: log in with your account in that window, close it, and run the prompt again.
If logging in from that window does not work, use the Open ChatGPT Tab button in the ThunderAI settings: it opens chatgpt.com in a Thunderbird tab, where you can log in. Then close the tab and go back to using ThunderAI.

5. Test the integration

Open any email, click the ThunderAI toolbar button, and select a prompt (e.g. Summarize). ThunderAI opens a ChatGPT window, sends the prompt and shows the answer there.

Advanced options

Click Advanced options in the Connection Settings panel to show these settings:

  • ChatGPT Web Model: the model to use. If it is empty or not valid, ChatGPT uses its default. It does not work with a free ChatGPT account.
  • ChatGPT Web Project and ChatGPT Web Custom GPT: a Project or Custom GPT to always use. Copy the value from the browser address bar when the Project (/g/PROJECT-ID-PROJECT-NAME/project) or the Custom GPT (/g/CUSTOM-GPT-ID) is open in ChatGPT. You can also set them on a single prompt, in the custom prompts page.
  • ChatGPT Web temporary chat: use a temporary chat.
  • Wait time for page load: how long, in milliseconds, ThunderAI waits for the ChatGPT page to load (default 1000). With a Project or Custom GPT, 1000 ms are added.

The Open ChatGPT Tab button also applies the configured model, Project and Custom GPT.

Tips and known limitations

  • Response speed depends on the ChatGPT website and may vary. The API integration is generally faster and more reliable.
  • Free accounts are subject to ChatGPT's own usage limits (rate limits, model availability).
  • If ChatGPT changes its website layout, the integration may temporarily stop working until ThunderAI is updated. Check the status page for any known issues.
  • The AI features listed in the settings page (Add Tags, Spam Filter, Summarize, Translate, Calendar Event and Task) need an API integration and do not work with the ChatGPT Web Interface. You can keep ChatGPT Web as the main connection and give each of these features its own API connection in its settings page. Your prompts from the toolbar menu keep working with ChatGPT Web.

Troubleshooting

The popup asks for a permission instead of showing the prompts

The chatgpt.com permission has not been granted yet. See step 3.

ThunderAI says you are not logged in, or shows no response

Log in to ChatGPT in the ChatGPT window opened by ThunderAI, close it and try again. If that does not work, log in from the tab opened by the Open ChatGPT Tab button in the ThunderAI settings.

"Could not locate the ChatGPT message box"

ThunderAI could not find the ChatGPT text box, usually after a change to the ChatGPT website. Click inside the ChatGPT text box within one minute and ThunderAI continues. If it happens every time, check the status page.

Responses are slow or time out

This is usually a temporary issue with the ChatGPT website. Wait a moment and try again, or consider switching to the OpenAI API integration for more reliable performance.
