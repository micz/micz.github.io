Die Integration mit der OpenAI Compatible API ermöglicht es Ihnen, ThunderAI mit jedem Server zu verbinden, der das OpenAI API-Format unterstützt.
Dies umfasst lokale Server wie LM Studio, gehostete Dienste wie DeepSeek, Grok, Mistral AI, OpenRouter und Perplexity sowie beliebige benutzerdefinierte oder selbst gehostete Endpunkte.

API-Schlüssel erforderlich Kostenlose Option Geeignet für
Variiert je nach Dienst Variiert je nach Dienst (lokale Server sind kostenlos) Flexibilität: lokale Server, alternative Anbieter, benutzerdefinierte Endpunkte

Vordefinierte Konfigurationen

ThunderAI enthält fertige Voreinstellungen für die beliebtesten OpenAI-kompatiblen Dienste. Wenn Sie einen dieser Dienste verwenden, wählen Sie einfach die Voreinstellung aus und geben Sie nur Ihren API-Schlüssel ein:

Voreinstellung Hinweise
DeepSeek API Schnell und kostengünstig, starke Reasoning-Modelle
Grok API Grok-Modelle von xAI
Mistral API Gehostete Modelle von Mistral AI
OpenRouter API Zugriff auf viele Anbieter über einen einzigen API-Schlüssel
Perplexity API Enthält Modelle mit integrierter Websuche

Einrichtung

Am schnellsten geht es mit dem Setup Wizard: Öffnen Sie ihn über die Willkommensseite von ThunderAI, das Popup in der Symbolleiste oder die Einstellungsseite, wählen Sie OpenAI Compatible API, wählen Sie einen Dienst oder geben Sie Ihre Serveradresse ein, wählen Sie ein Modell und testen Sie die Verbindung. Anschließend können Sie im Wizard die gewünschten KI-Funktionen aktivieren.
Für die manuelle Einrichtung folgen Sie den Schritten unten.

1. ThunderAI-Einstellungen öffnen

Gehen Sie in Thunderbird zu Extras → Add-ons und Themes → ThunderAI → Einstellungen.

2. OpenAI-Compatible-API-Integration auswählen

Wählen Sie im Bereich Connection Settings im Dropdown Connection Type die Option OpenAI Compatible API.

3a. Eine Vorkonfiguration verwenden

Wenn es für Ihren Anbieter eine Vorkonfiguration gibt, wählen Sie sie unter Available Services und bestätigen Sie. ThunderAI trägt die Serveradresse, die "v1"-Einstellung und den Chat-Namen ein und leert die Modellliste. Geben Sie Ihren API-Schlüssel ein und fahren Sie mit Schritt 5 fort.

3b. Manuelle Konfiguration

Wenn Ihr Anbieter nicht in der Liste steht, wählen Sie Custom und konfigurieren Sie ihn manuell:

  • Host Address: die Basis-URL Ihres Servers, ohne /v1. Für ein lokal laufendes LM Studio ist das in der Regel http://localhost:1234. Auch die Adresse eines entfernten Servers ist möglich.
  • Keep the "v1" compatibility (in den erweiterten Optionen, standardmäßig aktiviert): ThunderAI hängt /v1 an die Adresse an, wie in http://localhost:1234/v1/chat/completions. Deaktivieren Sie die Option, wenn die Endpunkte Ihres Anbieters kein /v1 enthalten.

4. API-Schlüssel eingeben (falls erforderlich)

Geben Sie ihn in das optionale Feld OpenAI Comp API Key ein. Lokale Server wie LM Studio benötigen normalerweise keinen API-Schlüssel, Sie können das Feld also leer lassen. Gehostete Dienste erfordern einen gültigen Schlüssel.

5. Modell auswählen

Klicken Sie neben OpenAI Compatible API Models auf Update list und wählen Sie dann Ihr Modell aus der Liste.

Stellt der Server keine Modellliste bereit, klicken Sie auf Add manually und geben Sie den Modellnamen so ein, wie Ihr Anbieter ihn angibt. Clear list leert die Liste.

6. Verbindung testen

Einstellungen werden gespeichert, sobald Sie sie ändern: Es gibt keine Speichern-Schaltfläche.
Klicken Sie in der Leiste unter den Verbindungseinstellungen auf Test now und bestätigen Sie die Berechtigungsanfrage von Thunderbird, falls sie erscheint. Wenn alles in Ordnung ist, zeigt die Leiste "Connected — OpenAI Compatible API reachable". Öffnen Sie dann eine beliebige E-Mail, klicken Sie auf die ThunderAI-Schaltfläche in der Symbolleiste und führen Sie einen Prompt aus.

Erweiterte Optionen

Klicken Sie im Bereich Connection Settings auf Advanced options, um diese Einstellungen anzuzeigen:

  • Keep the "v1" compatibility: siehe Schritt 3b.
  • Chat Name: der Name, unter dem die KI im ThunderAI-Chatfenster erscheint.
  • Temperature: zwischen 0 und 2. Höhere Werte machen die Ausgabe zufälliger, niedrigere fokussierter.
  • Extra body data: zusätzliche Parameter als JSON-Objekt, für Optionen, die der Dienst unterstützt, ThunderAI aber nicht anzeigt, z. B. {"top_p": 0.9} oder {"chat_template_kwargs": {"thinking": false}}, um den Denkmodus auf Servern, die das unterstützen, auszuschalten.

Sie können diese Optionen auch für einen einzelnen Prompt festlegen, auf der Seite der benutzerdefinierten Prompts, sowie für jede KI-Funktion (Add Tags, Spam Filter, Summarize, Translate, Calendar Event, Task), mit der Schaltfläche Advanced options ihrer spezifischen Verbindung.

LM Studio — Schnellkonfiguration

LM Studio bietet einen lokalen Server mit OpenAI-kompatibler API und eine grafische Oberfläche zum Herunterladen und Verwalten von Modellen.

  1. Laden Sie LM Studio von lmstudio.ai herunter und installieren Sie es
  2. Laden Sie ein Modell Ihrer Wahl über den Modellbrowser von LM Studio herunter
  3. Starten Sie in LM Studio den lokalen Server
  4. Wählen Sie in ThunderAI Custom, setzen Sie die Host Address auf http://localhost:1234, lassen Sie die "v1"-Kompatibilität aktiviert, lassen Sie den API-Schlüssel leer und wählen Sie Ihr Modell

Tipps

  • OpenRouter ist eine gute Wahl, wenn Sie über einen einzigen API-Schlüssel und ein Abrechnungskonto auf viele verschiedene Modelle zugreifen möchten (darunter Claude, Gemini und Mistral).
  • Bei lokalen Servern hängt die Leistung von Ihrer Hardware ab — Hardware-Tipps finden Sie in der Ollama-Anleitung.
  • Wenn Anfragen mit einem CORS-Fehler fehlschlagen und Sie die Serverkonfiguration nicht ändern können, klicken Sie in den ThunderAI-Einstellungen auf Give permission to the current host (unter "Problems setting CORS?"). Bei einem Server auf localhost oder 127.0.0.1 fragt Thunderbird nach Zugriff auf alle Websites (<all_urls>).
  • Wird das Rate-Limit oder Kontingent des Dienstes überschritten, während ThunderAI mehrere E-Mails verarbeitet (Add Tags, Spam Filter, Summarize, Translate), stoppt die Verarbeitung von selbst und meldet, wie viele Nachrichten verarbeitet wurden.

Fehlerbehebung

"Connection refused" bei einem lokalen Server

Stellen Sie sicher, dass der lokale Server (z. B. LM Studio) tatsächlich läuft und die Host Address in ThunderAI dem Port entspricht, auf dem er lauscht.

Fehler "401 Unauthorized"

Prüfen Sie Ihren API-Schlüssel. Bei lokalen Servern ohne Schlüssel versuchen Sie einen Platzhalterwert wie none. Manche Server lehnen ein leeres Schlüsselfeld ab.

Leere Modellliste

Klicken Sie auf Add manually und geben Sie den Modellnamen so ein, wie er in der Dokumentation Ihres Anbieters oder Servers steht.

"404 Not Found" oder Fehler durch "v1" in der URL

Prüfen Sie, dass die Host Address nicht auf /v1 endet, da ThunderAI es anhängt, wenn Keep the "v1" compatibility aktiviert ist. Haben die Endpunkte Ihres Anbieters kein /v1, deaktivieren Sie diese Option.
