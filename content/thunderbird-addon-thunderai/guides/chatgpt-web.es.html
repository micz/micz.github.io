La integración con la ChatGPT Web Interface te permite usar ThunderAI sin una clave de API.
ThunderAI interactúa directamente con el sitio web de ChatGPT en tu nombre, por lo que solo necesitas una cuenta gratuita de ChatGPT.

Clave de API requerida Opción gratuita Ideal para
No Sí (también con una cuenta gratuita de ChatGPT) Empezar rápidamente, sin configuración de facturación

Requisitos previos

  • Una cuenta gratuita (o de pago) en chatgpt.com
  • Thunderbird con ThunderAI instalado

Configuración

Lo más rápido es el Setup Wizard: ábrelo desde la página de bienvenida de ThunderAI, el popup de la barra de herramientas o la página de ajustes, y elige ChatGPT Web Interface. Después continúa desde el paso 3.
Para configurarla a mano, sigue todos los pasos de abajo.

1. Abre los ajustes de ThunderAI

En Thunderbird, ve a Herramientas → Complementos y temas → ThunderAI → Preferencias.

2. Selecciona la ChatGPT Web Interface

En el panel Connection Settings, elige ChatGPT Web Interface en el desplegable Connection Type.

3. Concede el permiso requerido

ThunderAI necesita permiso para acceder a chatgpt.com. No lo pide la página de ajustes, sino el popup de ThunderAI.

  1. Haz clic en el botón de ThunderAI en la barra de herramientas. Mientras falte el permiso, en lugar de la lista de prompts el popup muestra "To use the ChatGPT Web integration, you need to grant the required permission."
  2. Haz clic en ese mensaje: la página de bienvenida de ThunderAI se abre en una nueva pestaña.
  3. Haz clic en el mismo mensaje en la parte superior de la página de bienvenida y acepta la solicitud de permiso de Thunderbird.
  4. Cuando aparezca "Permission granted", haz clic en él para cerrar la pestaña.

Una vez seleccionada la ChatGPT Web Interface, también puedes abrir la página de bienvenida desde la tarjeta Open the Welcome Page en la parte superior de la página de ajustes: muestra la misma solicitud.

Este permiso es opcional y solo se usa para interactuar con el sitio web de ChatGPT en tu nombre. ThunderAI no recopila ni almacena ninguno de tus datos.

4. Inicia sesión en ChatGPT

Solo necesitas hacerlo una vez: Thunderbird mantiene la sesión activa.
La primera vez que uses un prompt, ThunderAI abre la ventana de ChatGPT. Si no has iniciado sesión, te lo indica: inicia sesión con tu cuenta en esa ventana, ciérrala y vuelve a ejecutar el prompt.
Si iniciar sesión desde esa ventana no funciona, usa el botón Open ChatGPT Tab en los ajustes de ThunderAI: abre chatgpt.com en una pestaña de Thunderbird, donde puedes iniciar sesión. Después cierra la pestaña y vuelve a usar ThunderAI.

5. Prueba la integración

Abre cualquier correo electrónico, haz clic en el botón de ThunderAI en la barra de herramientas y selecciona un prompt (p. ej. Summarize). ThunderAI abre una ventana de ChatGPT, envía el prompt y muestra allí la respuesta.

Opciones avanzadas

Haz clic en Advanced options en el panel Connection Settings para mostrar estos ajustes:

  • ChatGPT Web Model: el modelo que se usará. Si está vacío o no es válido, ChatGPT usa su modelo predeterminado. No funciona con una cuenta gratuita de ChatGPT.
  • ChatGPT Web Project y ChatGPT Web Custom GPT: un Proyecto o un Custom GPT que se usará siempre. Copia el valor de la barra de direcciones cuando el Proyecto (/g/PROJECT-ID-PROJECT-NAME/project) o el Custom GPT (/g/CUSTOM-GPT-ID) esté abierto en ChatGPT. También puedes definirlos en un solo prompt, en la página de prompts personalizados.
  • ChatGPT Web temporary chat: usar un chat temporal.
  • Wait time for page load: cuántos milisegundos espera ThunderAI a que cargue la página de ChatGPT (1000 por defecto). Con un Proyecto o un Custom GPT se añaden 1000 ms.

El botón Open ChatGPT Tab también aplica el modelo, el Proyecto y el Custom GPT configurados.

Consejos y limitaciones conocidas

  • La velocidad de respuesta depende del sitio web de ChatGPT y puede variar. La integración mediante API suele ser más rápida y fiable.
  • Las cuentas gratuitas están sujetas a los límites de uso propios de ChatGPT (límites de frecuencia, disponibilidad de modelos).
  • Si ChatGPT cambia el diseño de su sitio web, la integración puede dejar de funcionar temporalmente hasta que ThunderAI sea actualizado. Consulta la página de estado para conocer los problemas conocidos.
  • Las funciones de IA de la página de ajustes (Add Tags, Spam Filter, Summarize, Translate, Calendar Event y Task) necesitan una integración API y no funcionan con la ChatGPT Web Interface. Puedes mantener ChatGPT Web como conexión principal y asignar a cada una de estas funciones su propia conexión API en su página de ajustes. Tus prompts del menú de la barra de herramientas siguen funcionando con ChatGPT Web.

Solución de problemas

El popup pide un permiso en lugar de mostrar los prompts

Aún no se ha concedido el permiso para chatgpt.com. Consulta el paso 3.

ThunderAI indica que no has iniciado sesión, o no muestra ninguna respuesta

Inicia sesión en ChatGPT en la ventana de ChatGPT abierta por ThunderAI, ciérrala y vuelve a intentarlo. Si no funciona, inicia sesión en la pestaña que abre el botón Open ChatGPT Tab en los ajustes de ThunderAI.

"Could not locate the ChatGPT message box"

ThunderAI no encontró el cuadro de texto de ChatGPT, normalmente después de un cambio en el sitio web de ChatGPT. Haz clic dentro del cuadro de texto de ChatGPT en el plazo de un minuto y ThunderAI continúa. Si ocurre siempre, consulta la página de estado.

Las respuestas son lentas o agotan el tiempo

Suele ser un problema temporal del sitio web de ChatGPT. Espera un momento e inténtalo de nuevo, o considera cambiar a la integración OpenAI API para un rendimiento más fiable.
