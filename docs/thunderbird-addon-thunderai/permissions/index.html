"ThunderAI" Thunderbird Addon Permissions

These are the permissions used by ThunderAI in Thunderbird.
Remember that ThunderAI operates solely based on user interaction. Aside from automatic tagging and spam detection (if enabled), no actions are performed without direct user input within the add-on menu.

  • Access browser tabs
    Required to create a new email message or substitute the text the user has highlighted.
  • Download files and read and modify the browser's download history
    Needed for downloading the custom prompts export.
  • List message tags
    [From version 3.0.0]
    Required to use the tags related data placeholders and check if the tags received from the API are new or they have to be created, when using the "Add tags" option.
  • Read and modify your email messages as they are displayed to you
    Required to create a new email message or substitute the text the user has highlighted.
  • Read and modify your email messages as you compose and send them
    Required to create a new email message or substitute the text the user has highlighted.
  • Read your email messages
    Required to create a new email message or substitute the text the user has highlighted.
  • See your mail accounts, their identities and their folders
    Necessary to choose the correct mail identity when replying to an email.

Optional permissions
  • Access your data for all websites
    [From version 3.3.2]
    Granting this permission prevents any CORS issues with Ollama or some OpenAI Compatible APIs. It can be enabled via the corresponding button on the options page.
  • Access your data for sites in the anthropic.com domain
    [From version 3.5.0]
    Granting this permission prevents any CORS issues with the Claude API. It can be enabled via the corresponding button on the options page.
  • Access your data for sites in the chatgpt.com domain
    [From version 2.0.5, optional from version 3.4.0]
    Required to access the ChatGPT website using the web interface.
  • Change properties and tags of your email messages
    [From version 3.0.0]
    Required to assign tags to an email message when using the "Add tags" option.
  • Create, modify and delete message tags
    [From version 3.0.0]
    Required to create new tags when using the "Add tags" option.
  • Move, copy, or delete your email messages
    [From version 3.2.0]
    Required to move spam messages to the spam folder, if the automatic spam filter is enabled.
  • Read and modify your address books and contacts
    [From version 4.1.0]
    This permission is required to skip specific email addresses when using the antispam filter. Your contacts and address books will not be modified, and no addresses are sent to the AI service. All processing happens locally within Thunderbird to determine which emails should bypass the AI antispam analysis.

Removed permissions
  • Access your data for all websites
    [Removed in version 2.0.5]
    Required to access the ChatGPT website using the web interface. This permission was added at the first stages of development and never fixed.
  • Display notifications to you
    [Removed in version 2.1.0]
    The add-on shows a notification if you're trying to use the ChatGPT API integration, but the API key or model are invalid. In such cases, falls back to the web interface, showing a notification with the error. In version 2.1.0 the fallback to the ChatGPT web interface was removed.
